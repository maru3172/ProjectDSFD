**Daybook 독립 실행·오프라인 Git 작업 전환 진행 기록**

- 확정 범위: `협업툴_최종_보완_체크리스트.md`의 20개와 V1~V6.
- 추가 확정: 다른 두 팀원은 서버 운영 없이 프로그램 실행만으로 로컬 작성·저장. 공동 서버는 운영자가 켰을 때만 사용.
- 오프라인 변경 합치기는 Git으로 커밋·푸시·받아오기 후 파일 반영. 서버 재접속으로 자동 덮어쓰지 않음.
- Git 공유 자료와 서버의 로그인·승인·권한·세션은 분리. Git 자료를 가져왔다고 서버 접근 권한이 생기지 않음.
- 유료 호스팅·API·저장소를 최종 운영 필수 조건으로 사용하지 않음. 기존 전기·인터넷·PC 비용 별도.
- 기존 Sites 자료는 이전 검증 후 정리. 현재 클라우드 데이터 영구 삭제는 아직 하지 않음.
- 게임 프로젝트와 다른 에이전트의 작업은 수정하지 않음. 자동 Git 커밋·푸시 없음.

**진행 단계**

1. 구현·통합검사 완료: Node·로컬 SQLite·파일 저장소 기반 독립 실행과 인증, 기존 API 호환.
2. 구현·통합검사 완료: Git 자료 읽기·쓰기·충돌 검토, 기존 공간의 이전 모형 검증·암호화 전체 백업·새 설치 복원.
3. 구현·검사 완료: 업무·자료·공간 관리 항목과 탭 UI 연결.
4. 배포 마무리: 자체 포함 Windows 런처·Node 런타임·빌드 묶음. 실제 다중 PC 검증과 클라우드 영구 삭제는 미수행으로 구분.

이 기록의 단계 완료는 실제 구현과 검사 결과로만 갱신한다.
