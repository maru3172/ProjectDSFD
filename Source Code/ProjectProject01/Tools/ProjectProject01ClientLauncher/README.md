# ProjectProject01 클라이언트 업데이트 런처

이 프로그램은 서버에 게시된 클라이언트 매니페스트를 확인하고, 달라진 파일만 내려받아 무결성을 검사한 뒤 게임을 실행합니다.

## 최초 배포

1. `ProjectProject01 Build + Server Helper`에서 **클라이언트 패키징**을 실행합니다.
2. 패키징 성공 후 업데이트 매니페스트와 런처가 자동으로 생성됩니다.
3. `Builds/Client` 아래에서 `ProjectProject01.exe`가 들어 있는 Windows 패키지 폴더 전체를 압축해 사용자에게 한 번 배포합니다.
4. 사용자는 게임 실행 파일 대신 `ProjectProject01ClientLauncher.exe`를 실행합니다.

## 이후 업데이트

1. 새 코드나 콘텐츠를 반영한 뒤 서버 도우미에서 **클라이언트 패키징**을 다시 실행합니다.
2. 기존 패키지를 이미 만들었다면 **클라이언트 업데이트 게시**만 눌러 매니페스트를 다시 만들 수 있습니다.
3. 백엔드를 실행해 둡니다. 기본 업데이트 주소는 `http://서버IP:5080/api/client-updates/manifest`입니다.
4. 사용자는 런처에 서버 IP를 한 번 입력하고 **업데이트 후 게임 실행**을 누릅니다.

런처는 이전 매니페스트와 새 매니페스트를 비교하므로 변경된 패키지 파일만 다운로드합니다. 다운로드가 끝나면 SHA-256 해시를 확인하고, 적용 실패 시 기존 파일을 복구합니다.

## 주의사항

- 개발자는 새 실행 파일과 Unreal 콘텐츠를 만들기 위해 새 버전마다 패키징해야 합니다. 이 런처는 사용자에게 패키지 전체를 매번 다시 전달하는 작업을 줄여 줍니다.
- 게임이 실행 중이면 파일을 교체할 수 없으므로 게임을 종료한 뒤 업데이트해야 합니다.
- 서버 PC의 TCP 5080 포트가 클라이언트에서 접근 가능해야 합니다. MySQL 3307 포트는 외부에 열지 않습니다.
- 런처 자체는 업데이트 대상에서 제외됩니다. 런처를 변경한 경우에는 새 런처 파일을 별도로 다시 배포해야 합니다.
- 공개 인터넷 배포에서는 현재 HTTP 대신 HTTPS와 서명된 배포 파일 저장소를 사용하는 것이 필요합니다.
