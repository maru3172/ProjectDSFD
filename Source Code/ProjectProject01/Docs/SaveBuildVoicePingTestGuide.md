# 싱글 저장·빌드 도우미·생존자 통신 테스트 가이드

이 문서는 이번 구현의 실제 사용과 검증 절차를 한곳에 정리합니다. 붙잡힘·구출·공통 상호작용은 이번 범위에 포함하지 않습니다.

## 1. 싱글플레이 체크포인트 저장

### 수동 저장과 불러오기

1. 타이틀에서 `싱글 플레이`를 눌러 `LevelTest01`에 들어갑니다.
2. `F1` 메뉴에서 `현재 체크포인트 저장`을 누릅니다.
3. 위치를 옮기거나 스태미나·데스카운트를 변화시킵니다.
4. `F1` 메뉴에서 `마지막 체크포인트 불러오기`를 누릅니다.
5. 위치, 스태미나, 데스카운트가 저장 시점으로 복구되는지 확인합니다.
6. 타이틀의 `싱글 이어하기`로도 같은 저장을 불러올 수 있습니다.

저장 위치는 Unreal의 SaveGame 기본 경로 아래 `SinglePlayerCheckpoint` 슬롯입니다. 저장 중 중복 요청은 거부되며, 정상 저장 전의 유효한 주 슬롯은 백업 슬롯에 보존됩니다. 주 슬롯이 없거나 손상되면 백업을 검사합니다. 지원하지 않는 구버전·미래 버전·무결성 실패 파일은 적용하지 않습니다.

### 맵에 자동 체크포인트 배치

1. 에디터 Place Actors 또는 C++ Classes에서 `ProjectProject01Checkpoint`를 배치합니다.
2. `CheckpointId`에 위치를 구분할 이름을 지정합니다.
3. Trigger 박스 크기를 조절합니다.
4. 싱글플레이 로컬 플레이어가 들어가면 비동기 저장이 접수됩니다.

`bSaveOnlyOncePerSession`이 켜진 경우 저장 요청이 실제로 접수된 뒤에만 해당 체크포인트가 소모됩니다. 멀티플레이에서는 작동하지 않습니다.

## 2. Build + Server Helper

프로젝트 루트에서 다음 명령으로 실행합니다.

```powershell
dotnet run --project ".\Tools\ProjectProject01BuildServerHelper\ProjectProject01BuildServerHelper.csproj"
```

권장 순서는 다음과 같습니다.

1. UE Engine 경로, `.uproject`, 출력 경로를 확인하고 `환경 검사`를 누릅니다.
2. 필요하면 `MySQL 초기화/시작`을 누릅니다.
3. `백엔드 시작` 후 `/health` 상태를 확인합니다.
4. `클라이언트 패키징`을 실행합니다.
5. 소스 빌드 UE를 사용할 때만 `데디케이티드 서버 패키징`을 실행합니다.
6. 패키징된 서버가 있으면 `게임 서버 시작`으로 실행합니다.
7. 로그/빌드 폴더 버튼에서 결과와 실패 로그를 확인합니다.

Launcher Installed Build에서는 전용 서버 패키징을 도구가 명확히 차단합니다. DB 연결 문자열, 서버 서명 비밀키, 인증서는 Git이나 도구에 저장하지 않고 환경변수 또는 배포 환경에서 주입합니다.

## 3. 생존자 핑

기본 키는 `Z 도움`, `X 위험`, `C 위치`이며 환경설정에서 변경할 수 있습니다.

1. `MultiplayTest`에 마네킹 1명과 생존자 2명으로 입장합니다.
2. 생존자가 벽이나 바닥을 바라보고 핑 키를 누릅니다.
3. 두 생존자 화면에는 해당 지점의 표식이 보이고 마네킹 화면에는 보이지 않아야 합니다.
4. 탈락·탈출한 생존자에게는 표식이 전달되지 않아야 합니다.
5. 5초 안에 5회 이상 요청해 서버 호출 제한이 추가 요청을 차단하는지 로그로 확인합니다.

핑 지점은 서버가 최대 3,000cm 시야 트레이스로 계산하며 클라이언트가 임의 좌표를 제출하지 않습니다.

## 4. 생존자 근접 보이스

기본 키는 `F2 누르는 동안 말하기`, `U 상시 송신 전환`입니다. 환경설정에서 변경할 수 있습니다.

1. 두 클라이언트 모두 마이크 권한과 입력 장치를 확인합니다.
2. `Docs/SurvivorVoiceChatSetup.md`에 따라 각 개발 PC의 EOS Voice 설정을 준비합니다.
3. 생존자끼리 가까이 서서 F2로 송신되는지 확인합니다.
4. 거리를 벌려 350cm 이후 음량이 감쇠하고 1,800cm 밖에서 들리지 않는지 확인합니다.
5. 마네킹과 탈락·탈출한 생존자가 채널에서 제외되는지 확인합니다.

위치 갱신은 기본 0.1초 간격이며 매 프레임 공급자 호출을 하지 않습니다. EOS 설정이나 토큰이 준비되지 않아도 게임과 핑은 실패하지 않고 보이스만 비활성 상태로 남습니다.

## 5. 자동 검증

- `ProjectProject01.SinglePlayer.SaveIntegrityAndMigration`: 저장 무결성, 변조 거부, 지원 버전 마이그레이션
- 기존 `ProjectProject01.*` 자동화 테스트: 진단, 타이틀 경로, 멀티 승패, 심박/VFX, 스태미나, 설정 키, 튜닝 검증

실기 테스트에서는 자동화로 확인할 수 없는 마이크 장치, EOS 채널 접속, 실제 패키징 출력, 서로 다른 PC 사이의 음량 감쇠를 별도로 확인합니다.
