# 마네킹 명령 휠

마네킹 플레이어의 명령은 감정표현 같은 원형 UI로만 내린다. 예전 V/Z/X/C/Q/B 단축키는 없앴다(조작키 도움말·튜토리얼 문구도 휠 기준으로 바꿈). 숫자 키 0~9(번호로 마네킹 고르기·빙의)는 그대로다.

## 조작
- 오른쪽 클릭: 조준점 방향으로 넓은 스윕(반지름 60, 4000)을 쏜다. 마네킹에 맞지 않으면 조준점에서 7도 안쪽에 보이는(벽에 가리지 않은) 마네킹 중 가장 가까운 각도의 것을 고른다. 그래도 없으면 지금 보고 있는 마네킹(자신)에게 내릴 명령 휠이 열린다.
- 휠이 열려 있는 동안: 마우스 커서가 나오고 화면은 마우스를 따라 돌지 않는다. 이동 키는 계속 쓸 수 있다. 다른 마네킹을 골랐다면 카메라가 그쪽으로 천천히 돈다(초당 2.5 보간, 위아래 -25~15도로 제한해 어지럽지 않게). 자신이면 카메라는 그대로다.
- 칸은 선 없이 꽉 찬 도형으로 그린다. 명령 위에 마우스를 올리면 그 칸이 밝아지고 조금 커진다. 왼쪽 버튼을 누르고 있으면 눌린 색, 같은 칸에서 떼면 실행. 오른쪽 클릭(또는 Esc)은 명령 없이 닫는다.
- 고른 마네킹에는 마네킹 플레이어 화면에만 빨간 고리가 그려진다(화면 위에만 그리므로 생존자에게는 보이지 않는다).

## 명령 (위에서 시계 방향)
정찰 · 범위 추격 · 따라오기 · 정지 · 직접 조작 · 빙의 · 추종 해제 · 잡기 피해

- 정찰/범위 추격/따라오기/정지: 고른 마네킹에게 바로 지정. 정지는 휠로 새로 열린 명령이다(서버 `TryIssueMannequinCommand`가 HoldPosition도 받는다).
- 직접 조작: 다른 마네킹이면 먼저 그 마네킹으로 시점을 옮긴 뒤(번호 키와 같은 규칙) 조작한다.
- 빙의: 시점만 그 마네킹으로 옮긴다(AI는 유지). 자신을 고른 휠에서는 비활성.
- 추종 해제, 잡기 피해: 기존 Q, B와 같다(전체에 적용).

## 구현
- `Public/ProjectMannequinWheel.h`, `Private/ProjectMannequinWheel.cpp`: 휠 Slate 위젯(그리기·호버·누름·선택·취소) + 자동 검사 `ProjectProject01.MannequinWheel`(방향별 선택, 비활성 칸, 그림 `Saved/MannequinWheelQA`).
- `MultiplayTestPlayerController`: 오른쪽 클릭 바인딩, 레이, 커서·입력 모드, 카메라 따라가기, 서버 RPC `ServerRequestMannequinWheel(대상, 항목)`(명령 RPC와 같은 요청 한도).
- `MultiplayMannequinTypes.h`: `EMannequinWheelAction`.

## 확인하지 못한 것
- 실제 경기에서 오른쪽 클릭 조준, 카메라 따라가기의 느낌, 생존자 화면에 고리가 안 보이는지는 직접 확인하지 않았다.

## 2026-11-04 추가
- 대상 미리 보기: 휠이 닫혀 있을 때 조준점이 가리키는 마네킹(오른쪽 클릭 시 고를 대상과 같은 판정)에 옅은 고리와 번호가 계속 켜져 있다(깜빡이지 않음). 마네킹 플레이어 화면에만 그린다. 휠이 열리면 사라지고 휠의 빨간 고리로 바뀐다. `ProjectMannequinAimMarker.h/.cpp`.
- 열기·닫기 연출: 열 때 0.7배에서 1배로 커지며 0.14초 동안 나타나고, 명령을 내리거나 취소하면 0.75배로 작아지며 0.12초 동안 사라진다. 사라지는 동안에는 입력을 받지 않는다.
- 직접 조작을 끝낼 때(다른 마네킹으로 빙의): 조작 중 명령을 내리지 않았다면 사람 플레이어의 몸체는 직접 조작 전의 명령으로 그대로 돌아간다(기록이 없으면 정찰). 멈추는 것은 정지 명령을 받았을 때뿐이다. 서버 봇은 승률 조정 전제를 지키려고 기존대로 정지한다.
- 휠 가운데 "N번 마네킹" 바로 아래에 그 마네킹이 지금 하는 일(정찰 중·범위 추격 중·따라오는 중·정지 중·직접 조작 중)을 적는다. 매 프레임 읽으므로 새 명령을 내리면 바로 바뀐다.
