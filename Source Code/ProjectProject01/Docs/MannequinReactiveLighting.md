# 마네킹 반응 조명

기존 `AMannequinReactiveLight` 배치 액터를 그대로 사용한다. 타이틀 전용 조명·손전등·출구 표시·일반 조명에는 자동으로 덧씌우지 않는다. 싱글과 멀티의 클라이언트에서 표현하며 전용 서버는 실행하지 않는다.

현재 강도(후속 요청 반영): 기본 광량 6500, 전구 발광 7, 전기 잡음 음량 배율 0.45. 고장 깊이는 85~100%에서 선택하고 광량 변화 대비는 `min(1, 1.35 × sqrt(강도))`를 쓴다. 최소 잔광·패턴 5종·발생 간격·3개 단위 단계·접근성 설정은 유지한다.

## 발생 기준

- 로컬 카메라 주변 `DetectionRadius`(기존 기본값 15m) 안의 마네킹 몸체를 센다. 시선·동결·직접 조작 여부와 무관하다.
- 0~2개는 새 고장을 발생시키지 않는다. 3~5 / 6~8 / 9개 이상이 세 단계다.
- 같은 층의 가까운 몸체가 주변 조명에 영향을 준다. 카메라와 몸체의 기본 수직 허용 간격은 4.5m다. 천장 전등은 이 간격으로 제외하지 않고 자체 광원 도달 범위까지 허용한다(기존 맵의 12.8m 천장 포함).
- 거리와 조명 위치로 강도를 보간한다. 화면 전체 밝기를 함께 바꾸거나, 전등이 마네킹의 정확한 위치를 알려 주지는 않는다.

## 고장 패턴

1. 전압이 처지고 머뭇거리다 천천히 회복.
2. 한 번 짧게 어두워졌다 복구.
3. 시간차를 둔 두 번의 깜빡임.
4. 점등을 시도하다 실패한 뒤 재복구.
5. 낮은 밝기로 오래 버티고 불완전하게 복구.

같은 패턴은 바로 연속 선택하지 않는다. 지속 시간·깊이·고장 사이의 정상 유지 시간·소리 발생 여부를 사건마다 뽑으며 렌더 프레임마다 난수를 뽑지 않는다. 강도가 높아져도 반복 속도만 무한히 올리지 않고 낮은 밝기의 지속 시간과 발생 빈도를 늘린다. 각 전등은 별도 시드로 시작하므로 모두 동시에 꺼지지 않는다. 범위를 벗어나도 진행 중인 고장은 강도가 서서히 줄며 끝난다.

구분 강화: 느린 전압 저하는 짧은 깜빡임을 섞지 않고 수 초 동안 내려갔다 복구한다. 한 번 끊김은 약 1초 안팎으로 짧게 끝나며, 두 번 끊김은 중간에 정상 밝기를 충분히 유지한다. 점등 실패는 두 차례 재점등을 실패한 뒤 복구한다. 낮은 밝기 잔류는 그보다 오래 유지한다. 거리가 멀거나 천장이 높아도 시간 구조를 읽을 수 있도록 광량 변화에 연속적인 제곱근 대비 곡선을 적용한다. 밝기 상한·하한과 접근성 배율은 그대로다.

## 광량과 소리

- 원래 광량보다 밝아지는 섬광 없음. 정상 광량의 최소 18%를 남기며 `MinimumBrightnessFraction`으로 조절한다.
- Spot Light와 전구의 기존 emissive 파라미터를 함께 조절한다. 배치 메시·기존 광량·머티리얼은 보존한다.
- 전등 위치에서 낮은 전기 웅웅거림과 거친 잡음을 합성한다. 사건 중 일부는 무음이다. 3D 위치·거리 감쇄·벽 차폐·SFX 음량 설정을 따른다.
- 번쩍임 설정 0은 정상 광량 유지, 부분 설정은 변화량 축소. 다른 클라이언트 설정에는 영향을 주지 않는다.
- 경기 결과 상태, 액터 종료·맵 전환·체크포인트 복원에서는 음원을 정리한다. 복원 후 감지와 연출을 새로 시작한다.

## 비용 및 규칙 분리

몸체 위치 목록은 월드별 저빈도 캐시를 공유한다. 고장 강도가 남아 있는 조명만 30Hz로 보간한다. 먼 조명은 전기 음원을 생성하지 않는다. AI 시야·시선 정지·충돌·이동·피해 판정과 서버 규칙은 변경하지 않는다.

검사 항목: 3개 단위 경계, 거리 강도, 패턴 다양성·연속 반복 방지, 고정 시드 재현, 광량 하한·상한, 위협 해제 후 복구, 2개 이하 비활성, 로컬 접근성 회귀. 다중 PC·실제 맵의 조명 배치·체감 밝기와 음량은 플레이 확인 대상이다.
