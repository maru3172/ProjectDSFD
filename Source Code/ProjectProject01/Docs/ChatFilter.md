# 금칙어 필터 (2026-11-11)

다른 플레이어가 보는 글에 욕설·비하 표현이 그대로 나가지 않게 서버에서 거른다. 클라이언트는 바꾸지 않았다(서버가 돌려준 결과를 그대로 보여 준다).

## 어디에 적용하나

| 글 | 처리 |
| --- | --- |
| 방 채팅, 귓속말 | 금칙어만 `*`로 가려서 보낸다. 나머지 문장은 그대로. |
| 표시 이름(가입), 방 이름, 상태메시지·소개글, 공유 게시판 글의 이름·한 줄 소개 | 금칙어가 있으면 저장하지 않고 "사용할 수 없는 말이 들어 있습니다"를 돌려준다. |
| 문의, 신고 사유, 운영자 공지 | 거르지 않는다(운영자만 보거나 운영자가 쓴 글). |

이미 저장된 글에는 적용하지 않는다. 목록을 바꾼 뒤 새로 쓰는 글부터 적용된다.

## 찾는 방식

- 대소문자, 띄어쓰기, 기호, 보이지 않는 문자를 사이에 넣어도 찾는다(예: `시 . 발`, `씨-발`, `FuCk`). 가릴 때는 사이에 넣은 기호까지 함께 `*`로 바꾸고 띄어쓰기는 남긴다.
- **허용 단어** 안에 든 금칙어는 막지 않는다(예: `시발점`). 같은 문장에서 허용 단어 밖에 나온 금칙어는 가린다.
- 기본 목록은 흔한 한국어·영어 욕설과 초성 줄임말이다. 일상어와 겹치는 말(`새끼` 고양이, `보지` 마, `자지` 말고, `졸라`)은 일부러 넣지 않았다.
- 기본 목록은 처음 한 번만 넣는다. 운영자가 지운 단어는 다시 생기지 않는다.

## 운영 도우미

서버 운영 › 계정·신고 › 계정·신고 관리 › **금칙어 관리**.
- 왼쪽에 금칙어, 오른쪽에 허용 단어를 한 줄에 하나씩 적는다(모두 2000개, 하나에 40자 이하).
- **시험**: 저장하기 전 목록으로 문장을 넣어 보면, 채팅으로 보낼 때의 결과와 이름·글로 쓸 때 거부되는지를 보여 준다.
- 저장하면 바로 적용된다(서버는 목록을 30초마다 다시 읽고, 저장 직후에는 바로 읽는다).
- 운영자 권한: 고객지원(`Support`) 키로 관리할 수 있다.
