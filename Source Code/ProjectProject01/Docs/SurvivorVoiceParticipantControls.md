# 생존자 동료별 보이스 제어

## 사용

경기 중 ESC → 환경설정 → 사운드 → **음성 채팅 장치·음량·마이크 테스트**에서 동료 생존자를 선택한다.

- **선택한 동료 음소거 / 해제**는 즉시 내 수신에만 적용한다.
- **선택한 동료 음량** 게이지는 0~100%로 즉시 적용한다. 음소거를 풀어도 이 음량은 유지된다. 0%는 별도의 음소거 체크 상태를 변경하지 않는다.
- 기존 전체 보이스 수신 음량, 전체 음량/음소거/백그라운드 음소거 및 EOS 거리 감쇄를 대체하지 않는다. 동료별 음량은 추가적인 수신 조절이다.
- 동료별 설정은 현재 음성 경기 세션 한정이다. 채널 연결 끊김 후 재참가/동료 재참가 시 다시 적용하고, 경기에서 나가기·역할 재구성·맵 이동에 따른 기존 LeaveMatch 경로에서는 초기화한다. 장치/전체 보이스 수신 음량은 기존대로 로컬 PC에 저장한다.
- 초기화는 장치·전체 수신 음량·동료별 음량/음소거를 즉시 기본값으로 돌린다. 장치와 전체 수신 음량을 바꾼 경우에는 기존 적용 버튼으로 저장한다. 돌아가기는 이미 즉시 적용된 동료별 설정을 취소하지 않는다.
- 목록은 실제 생존자 음성 채널에 참가한 사람만 보여준다. 기존과 같이 EOS 식별자의 끝 6자리로 구분하며 계정 닉네임과 EOS ID를 새로 서버에 연결하는 기능은 추가하지 않았다.
- 동료가 없거나 채널 연결 전에는 선택/음소거/동료 음량을 비활성화한다. 작은 화면에서는 설정 내용을 스크롤할 수 있다.

## 실제 발화 표시와 역할 격리

- 우측 상단 기존 내 보이스 활성/비활성 표기는 그대로 유지한다.
- 아래 동료 상태는 EOS `IVoiceChatUser::IsPlayerTalking` 결과로 **말하는 중 / 대기**를 표시한다. F2/U를 누른 사실로 상대의 발화를 추측하지 않는다.
- 내 수신에서 음소거된 동료는 **음소거됨**, 0% 동료는 **수신 음량 0%**를 우선 표시한다.
- HUD는 0.1초, 열린 설정의 동료 목록/상태는 0.2초마다 갱신한다. 선택은 참가자 순서가 바뀌어도 가능한 한 같은 ID로 유지한다.
- 목록·상태·설정 변경은 생존자 채널 가입 여부를 확인한다. 마네킹은 기존대로 이 채널에 가입하지 않고, 보이스 HUD도 숨긴다. 발화나 음소거 정보를 게임 RPC/복제 속성으로 추가 전송하지 않는다. 다른 생존자는 자신의 수신 설정에 영향을 받지 않는다.
- Unreal EOSVoiceChat의 로컬 `SetPlayerMuted` / `SetPlayerVolume` API를 사용한다. 상대 플레이어에게 음소거 알림을 보내는 별도 기능은 없다.

## 확인 방법

1. 서로 다른 두 PC의 생존자와 마네킹 1명으로 경기 시작. 정상 EOS 음성 연결이 선행되어야 한다.
2. 한 생존자가 송신 키만 누르고 조용히 있다가 실제로 말한다. 다른 생존자의 동료 상태가 실제 발화에 반응하는지 확인한다(환경 잡음도 음성 감지에 영향을 줄 수 있다).
3. 듣는 쪽에서 동료 음량을 100 → 40 → 0%로 변경한다. 자신에게 들리는 해당 동료 음성만 바뀌고 다른 소리/상대의 설정은 바뀌지 않아야 한다.
4. 40%에서 음소거 후 해제한다. 해제 시 40%가 유지되어야 한다. 다른 플레이어에게 음소거 알림이 뜨면 안 된다.
5. 동료 재참가/음성 채널 재연결 후 같은 경기의 설정이 다시 적용되는지 확인한다. 새 경기에서는 기본값으로 시작한다.
6. 마네킹 화면에는 동료 보이스 상태나 음성 설정 참가자 목록이 없어야 하고, 생존자 대화도 들리면 안 된다.
7. 동료가 나간 직후 버튼/게이지를 조작해도 잘못된 대상을 변경하거나 예외가 발생하면 안 된다.
8. 전체 음량·백그라운드 음소거·거리 감쇄·설정 초기화를 함께 확인한다.

자동 검사는 입력 장치를 열거나 EOS 통화를 시작하지 않는다. 실제 음성 수신·거리 감쇄·서비스의 음성 감지 품질은 위 두 PC 검사로 확인해야 한다. 패키징/운영 서버 재시작/업데이트 게시는 이번 코드 작업에서 실행하지 않는다.

## 자동 검증 (2026-10-16)

- Win64 Development Editor 및 Win64 Shipping 빌드 성공.
- 기존 회귀 검사와 신규 보이스 검사를 합해 34개 성공, 실패/미실행 0개. 결과: `Saved/VoiceParticipantNative/index.json`.
- 음소거·게인 독립성, 다른 참가자/본인/채널 밖 대상 차단, 0~100% 범위, NaN/무한대 거부, 종료 시 정리, 생존자 서비스가 없을 때 정보 숨김과 조작 비활성화를 검사했다.
- 1280×720 / 800×600으로 설정 화면을 렌더링하고 이미지도 확인했다. 작은 화면은 스크롤을 사용하며 제목 여백과 동료 음량 게이지 배치가 유지된다. 결과: `Saved/VoiceParticipantTests/VoiceSettings_*.png`.
- 이 검증은 실제 두 PC 사이 EOS 통화 성공을 의미하지 않는다.
