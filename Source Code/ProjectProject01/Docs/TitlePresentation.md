# 타이틀 전용 3D 연출

## 범위

- `AProjectProject01TitlePlayerController`만 로컬 `AProjectDFSDTitleScene`을 생성한다. AI/Pawn이나 멀티 복제 객체가 아니다. 타이틀을 나가면 세트가 제거된다.
- 실제 경기용 마네킹·AI·공격·피격 VFX·SFX·게임플레이 맵은 수정하지 않는다.
- 최초 실행의 학교 로고 → Team DSFD → 타이틀 순서는 유지한다. 같은 실행에서 타이틀로 돌아오면 로고는 반복하지 않는다.
- UI는 왼쪽, 3D 마네킹은 오른쪽이다. 카메라와 메뉴가 동일한 16:9 안전 프레임에 맞춰진다. 4:3/울트라와이드는 비율을 늘이거나 자르지 않고 여백을 둔다.

## 표현

- 마네킹은 뒤로 물러선 위치에서 몸을 사선으로 세우고 목을 화면 방향으로 돌린 고정 자세다. 런타임 컴포넌트의 포즈만 변경하며 공용 스켈레톤/애니메이션 자산은 변경하지 않는다.
- 조명은 마네킹 얼굴 정면이 아니라 옆을 비추어 빛의 경계에 서 있는 구도를 만든다. 수동 노출을 고정해 조명이 어두워질 때 자동 노출이 화면을 다시 밝히지 않게 한다.
- 첫 조명 변화는 2.5~5.5초 후 무작위로 시작하며, 각 이벤트가 끝나면 7~13초 쉰다. 1.8초 이벤트 안에서 한 번 또는 두 번 짧게 깜빡인다(각 50%). 타이틀 진입마다 새 로컬 시드를 사용하므로 같은 순서를 재생하지 않는다. 각 깜빡임은 0.09초 어두워짐 + 0.10초 유지 + 0.16초 복귀이며, 두 깜빡임 사이에는 정상 밝기로 돌아온다. 주 조명만 최저 16%로 줄이고 보조광/윤곽광/UI는 유지한다. 흰 섬광/전체 화면 소등/연속 고주파 점멸은 사용하지 않는다.
- 바닥 가까운 옅은 안개 4장, 먼지·재 입자 24개가 천천히 움직인다. 2개 동적 머티리얼을 공유하고 충돌/내비게이션/그림자는 끈다.
- 번쩍임 감소 설정은 조명 변화량, 화면 흔들림 설정은 매우 느린 카메라 이동량, VFX 강도 설정은 안개·먼지 투명도에 연결된다.
- 가독성용 검은 그라데이션은 메뉴 아래에만 놓는다. 저장소 UI·삭제/새 게임 확인창·싱글 시작 암전과 버튼 동작은 유지한다.

## 자산과 패키징

- `Content/MyProject/Title/M_TitleSurface.uasset`
- `Content/MyProject/Title/M_TitleMist.uasset`
- `Content/MyProject/Title/M_TitleDust.uasset`

`Config/DefaultGame.ini`의 `/Game/MyProject/Title` AlwaysCook 설정과 런타임 하드 참조로 포함한다. `Tools/CreateTitlePresentationMaterials.py`는 최초 자산 생성용이며 기존 머티리얼 그래프는 덮어쓰지 않는다. 표면 머티리얼에는 SkeletalMesh 사용 플래그도 저장하며, 기존 자산의 이 플래그가 빠졌을 때만 보완한다. 게임 실행/배포 시 Python이나 에디터가 필요한 구조는 아니다. 기존 VFX 생성/복구 버튼과도 분리되어 있다.

## 검증

- `ProjectProject01.Frontend.TitleScene`: 장식 전용·충돌/AI 없음·조명 변화·접근성 설정·업데이트 중단.
- `ProjectProject01.Frontend.TitleSceneRender`: 실제 3D 캡처와 실제 메뉴를 합성하여 1280×720, 800×600, 1920×800에서 크기/배치 확인.
- `ProjectProject01.Editor.TitlePresentation`: 실제 타이틀 맵 PIE에서 최초 인트로, 전용 카메라, 로그인 맵 이동 후 세트 정리, 타이틀 복귀 시 로고 미반복 확인.
- 이미지: `Saved/TitleSceneQA`. 검사 보고서는 `Saved/ReviewRemediation` 아래 저장한다.
- 실제 게임/데디 서버 패키징이나 업데이트 게시, 운영 DB 변경은 하지 않는다.

- .NET 패키징 설정 단독 검사 26건 통과. 게임/서버 패키징은 수행하지 않았다.

### 조명 후속 조정

- 주 조명 1700 → 2000 lm(약 18% 증가), 약한 정면 보조광 35 → 42 lm. 카메라 노출·사선 구도·주 조명의 방향/범위는 유지한다.
- 기존의 완만한 어두워짐/미세 떨림을, 간헐적으로 한두 번 명확하게 깜빡이고 돌아오는 형태로 바꿨다. 번쩍임 설정 0이면 깜빡임도 완전히 꺼진다.
- 빌드 성공. `Saved/ReviewRemediation/TitleBlink-20261020/index.json`: 타이틀 동작/실제 렌더/실제 PIE 왕복 3건 성공, 실패·미실행 0. 위와 동일한 엔진 및 백엔드 비실행 경고는 유지되며, 깜빡임의 부드러운 경계·중간 복귀·한 번/두 번 분기·접근성 비활성화를 검사했다. 패키징은 하지 않았다.
- 몸통/발의 방향도 화면 쪽으로 15도 더 돌려, 시선과 몸이 약 33도 이내의 자연스러운 사선을 이루게 했다. 위치/크기는 유지하고 고개를 돌리는 양만 줄인다.
- `Saved/ReviewRemediation/TitleGazeRandom-20261020/index.json`: 랜덤 한 번/두 번 패턴·대기 간격·사선 자세·실제 렌더·타이틀 PIE 왕복 검사 3건 성공, 실패·미실행 0. 64개 이벤트를 고정된 테스트 시드로 검사해 두 패턴이 모두 나오고 대기 간격이 변하는 것을 확인했다(런타임은 진입마다 새 시드). 기존 엔진/백엔드 비실행 경고는 동일하다. 빌드 성공, 패키징 미수행.
