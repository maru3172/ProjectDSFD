# 프로필·컬렉션·시즌 뽑기

- 개인 기록에서 소개 글과 대표 업적 최대 3개를 편집한다. 서버에 달성 기록이 있는 업적만 지정하며 선택 순서를 보존한다. 다른 플레이어가 프로필을 열 때 동일한 배너·명찰·도장·배지·업적을 본다.
- 배너는 하단 프로필의 이름 영역에 낮은 대비로 깔리며, 오픈매칭 방에서는 닉네임 옆 작은 명찰로 표시된다. 프로필 카드·경험치 바·파티 간격은 유지하고 역할 선택은 계속 행 맨 우측에 둔다. 방 참가자의 배너는 서버의 실제 장착 슬롯을 한 번의 목록 조회에 합쳐 전송하므로 다른 참가자에게도 보이며 클라이언트가 임의의 배너를 방 상태에 지정할 수 없다.
- 프로필에는 보유 배너를 여러 개 전시하고 대표 1개를 지정한다. 컬렉션의 전시/전시 해제/대표 지정으로 관리한다. 하단 프로필·방 명찰에는 대표만 사용한다. 대표 전시를 해제하면 남은 전시 배너 중 첫 배너로 전환하며, 전시를 모두 해제해도 보관함의 아이템은 삭제하지 않는다. 기존 장착 배너는 새 전시 목록으로 보존한다.
- 업적 전용 수집품은 `CaseCollection.Items`에 정의한다. 기존 달성 업적도 다음 계정 기록 조회 시 보관함에 소급 반영한다. 미로그인 싱글 업적은 기존 계정 병합 과정을 유지한다.
- 컬렉션은 페이지당 3개로 표시하며 보유한 꾸미기만 장착할 수 있다. 배너·Frame·Icon·Nameplate·Stamp·Badge는 서로 다른 장착 슬롯이다. 실제 경기 능력이나 시야·소리에는 영향을 주지 않는다.
- 전용 재화 1개 = 기존 500포인트. 1개/5개 뽑기는 각각 재화 1개/5개를 소비한다. 하위 등급의 꾸미기 중복은 5포인트, 자투리 포인트 상품은 운영 설정의 소량 포인트를 지급한다.
- 뽑기 전에는 상품만 진열하고 상자는 표시하지 않는다. 뽑기에 성공한 뒤 선택한 수량의 상자가 등장한다. 재화가 모자라면 추첨 요청 없이 재화 표시 아래에 `재화가 부족합니다`를 띄우고 서서히 지운다. 서버도 별도로 잔액을 확인한다.
- 컬렉션은 전체·배너·도장/인장·명찰·배지·테두리·아이콘으로 분류한다. 기존 상점 꾸미기와 보유한 레벨/조사 보상도 해당 분류에서 볼 수 있다.
- 에디터 뽑기 화면의 `+5,000 P`는 고정 5,000포인트를 지급한다. 서버 운영 → 시즌 뽑기 상품·확률 → `에디터 디버그 허용`을 켜고 같은 PC의 127.0.0.1 백엔드에 접속해야 한다. 허용 상태는 백엔드 재시작 시 꺼진다. 관리자 키 없는 허용 변경·외부/프록시 경유·일반 클라이언트 지급 요청은 차단하며 패키징에는 버튼을 넣지 않는다. 지급 재시도는 요청 ID로 중복 방지하고 XP·미션·주간 상한 집계는 변경하지 않는다.
- 결과 상자는 개별 개봉할 수 있다. 모두 개봉은 미개봉 상자들만 같은 시각에 각자의 정상 개봉 연출을 시작한다. 이미 열린 상자의 시작 시각과 연출은 유지한다. 최고 2등급의 봉인선과 짧은 국소 광원만 절제하여 강조하며, 전체 화면 섬광이나 카메라 흔들림을 추가하지 않는다. 개봉 조작은 재추첨·재화 차감을 하지 않는다.
- 1·2등급은 각각 단독 화면을 사용한다. 2등급은 틈을 천천히 열고 빠르게 상품을 공개하며, 1등급은 더 길게 뜸을 들이고 상자만 잠깐 흔든 뒤 공개한다. 여러 희귀 보상은 별도 화면을 순서대로 확인한다. 각 등급의 낮은 채도 봉인 색은 구분하되 전체 UI를 번쩍이게 하지 않는다.
- 단독 화면에서 공개 전 좌클릭은 상품 공개 단계로 바로 이동한다. 상품 등장 연출이 끝난 뒤 좌클릭은 다음 희귀 보상 또는 전체 결과로 이동한다. 같은 입력으로 공개와 확인을 함께 처리하지 않으며, 서버 상태 갱신으로 건너뛴 연출이 재시작되지 않는다.
- 1등급이 최고이며 총 5등급이다. 상위 2등급은 획득 후 재등장하지 않는다. 보관함 및 영구 획득 원장을 함께 확인하므로 새 시즌이나 일반 사이클 초기화가 기존 희귀 획득을 지우지 않는다.
- 미획득 1등급이 있을 때 100번째까지 1등급을 보장한다. 1등급 획득 시 일반 사이클과 천장 카운터를 초기화한다. 상위 등급 보유 목록은 그대로 유지한다. 해당 시즌의 모든 1등급을 얻었다면 추가 1등급을 중복 지급하지 않는다. 상위 상품 소진 후에도 누적 횟수와 스택은 기록한다. 5개 뽑기 도중에도 매 추첨마다 남은 상품과 천장을 다시 계산한다.
- 현재 추첨 확률은 미획득 상위 상품과 반복 가능한 하위 상품의 가중치를 정규화한 값이다. 확률 확인 창에서 현재 일반 추첨과 보장 추첨 확률을 별도로 표시한다. 획득 제외에 따라 비율이 변한다.
- 운영: 서버 도우미 → 서버 운영 → 콘텐츠·소통 → 사건 기록·보상 → 시즌 뽑기 상품·확률. 시즌 ID·제목·한국 시간 시작/종료·5등급 상품·가중치·공개 여부를 편집한다. 확률은 아직 미정이므로 기본 초안은 가중치 0, 비공개이며 임의의 1%/5% 등을 적용하지 않는다.
- 한 번 공개한 상품의 ID·아이템·등급·포인트 구성은 유지하며, 같은 시즌에 새 상품을 추가할 수 있다. 확률 가중치와 기간·공개 상태는 수정 가능하나 설정 버전을 갱신한다. 이전 버전으로 결제하려는 요청은 차감 없이 거절한다.
- 재화 차감·추첨·아이템 및 포인트 지급·천장·요청 영수증을 한 DB 트랜잭션으로 처리한다. 동일 요청 ID 재시도는 기존 결과를 반환하고 다시 차감하지 않는다. 접속 실패 때 클라이언트는 같은 요청 ID를 보존한다. 보상 액수·결과·천장은 클라이언트가 정할 수 없다.
- 백엔드 재시작 시 추가 테이블을 생성하며 기존 계정/경기 기록은 삭제하지 않는다. 새 게임 UI는 다음 클라이언트 패키징/업데이트 때 포함된다. 실제 운영 확률 공개, 운영 DB 접속, 패키징은 이번 작업에서 수행하지 않는다.

검증: `CaseDrawChecks` (격리 MySQL/HTTP), `--draw-rules` (DB 없는 규칙 검사), `ProjectProject01.CaseRecords.RenderPages` (실제 렌더 이미지).

## 2026-10-28 조정

- 50회 반천장은 1등급과 2등급을 각각 50%로 먼저 선택하고, 선택한 등급 안에서는 남은 상품 가중치로 추첨한다. 100회는 미획득 1등급 확정이다. 1등급이 일찍 나와도 사이클을 초기화하며, 일반 추첨에서 2등급을 얻었다고 100회 카운터를 초기화하지 않는다. 5개 추첨에서도 매 회차 재계산한다.
- 한 등급을 모두 획득했다면 반천장은 미획득 상품이 있는 다른 상위 등급으로 대체한다. 두 등급 모두 소진되면 이미 얻은 상위 상품을 재지급하지 않는다. 확률 창에는 대체 후 실제 상품별 확률을 표시한다.
- 기본 초안은 총 29종(꾸미기 28종과 포인트 1종)이다. 기존 공개 시즌의 구성은 덮어쓰지 않는다. 미설정 상태의 옛 5종 초안도 조회 시 29종으로 확장한다. 추가 상품은 배너, 테두리, 명찰, 도장·인장, 배지, 아이콘이며 게임 능력에는 영향을 주지 않는다. 확률 가중치는 여전히 미정(0)이고 운영자가 공개해야 실제 추첨이 가능하다.
- 버튼은 로그인 후 요청 처리 중을 제외하면 누를 수 있다. 미공개 뽑기는 안내만 표시하며 차감·상자 생성은 하지 않는다. 재화 교환은 시즌 공개 여부와 무관하게 가능하다.
- 좌상단에 1개 교환, 지정 수량 교환, 최대 교환을 둔다. 최대 교환은 현재 포인트를 500으로 나눈 몫이며 실제 잔액은 서버가 다시 확인한다. 중앙에는 2·1·3등급 상품을 배치하고 등급별로 넘겨볼 수 있다. 좌하단에 1개/5개 뽑기를 둔다.
- 에디터의 획득 초기화는 운영 허용·직접 로컬 접속·에디터 표식을 모두 요구한다. 해당 계정 전체의 뽑기로 처음 지급한 아이템과 획득 이력·보장 카운터를 초기화한다. 장착·배너 전시도 정리한다. 포인트, 뽑기 재화, 경험치, 업적, 다른 경로로 보유한 아이템은 보존한다. 이전 버전도 희귀 획득 원장과 중복이 아닌 획득 영수증으로 출처가 확인된 보상은 초기화한다. 초기화가 끝난 영수증에 완료 표식을 남겨 다시 적용하지 않아 이후 다른 경로로 얻은 아이템을 보존한다. 영수증은 중복 결제 방지를 위해 보존한다. 이 버튼은 패키징에 포함되지 않는다.
- 업적의 표시 이름은 업적·도전과제로 변경했다. 이벤트 탭은 빈 상태로 추가했으며 이벤트 지급·기간·보상은 활성화하지 않았다.
## 계정 초기화·스택 동기화 수정

- 에디터 초기화는 현재 계정의 전 시즌 뽑기 획득을 대상으로 한다. 기존 획득 원장·새 획득 테이블·구버전 영수증을 함께 확인하고, 장착과 전시를 정리한다. 다른 계정, 업적, 비뽑기 아이템, 포인트, 뽑기 재화는 유지한다. 영수증은 중복 결제 방지를 위해 보존하며 초기화 전 뽑기 재시도는 409로 차단한다.
- 매 정상 추첨에서 스택을 1 올리며 1등급 획득 때만 0으로 돌린다. 상위 상품을 전부 소유했더라도 스택은 100까지 증가하고 누적 뽑기 횟수는 계속 증가한다. 재시도는 둘 다 중복 증가시키지 않는다.
- 추첨·교환·초기화와 그 재시도 응답에는 같은 트랜잭션에서 조회한 전체 계정 상태를 포함한다. 클라이언트는 재화, 보유 상품, 장착, 스택을 동시에 반영한다. 초기화 성공을 받은 뒤에만 이전 개봉 연출을 닫는다.
- 서버 운영의 시즌 뽑기 상품·확률 창에 기본 29종 채우기를 추가했다. 기존 행과 가중치는 보존하며 빠진 상품만 채운다. 새 상품의 일반 확률 가중치는 0(미정)이므로 운영자가 정한 뒤 적용한다. 기존 상품 삭제·등급·보상 변경은 계속 막고 신규 상품 추가는 허용한다.
