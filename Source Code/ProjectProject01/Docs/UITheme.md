# 게임 UI 공통 타이틀 테마

## 적용 범위

`ProjectDFSDUITheme.h/.cpp`가 타이틀에서 사용하던 반투명 어두운 버튼, 밝은 본문, 붉은 강조색을 공통으로 제공한다. 로그인·회원가입, 환경설정, 로비·방·매칭, 리더보드, 저장소, 일시정지, 설문, 역할 가이드·튜토리얼, 친구·귓속말·신고·프로필, 음성 설정과 상호작용 안내에 연결했다. 탈출·사망·경기 결과창은 이후 요구대로 공통 사건 파일 프레임에서 제외했다.

가독성 조정: 타이틀 홈의 여섯 버튼은 `TitleButtonStyle`로 원래 반투명 표면을 유지한다. 다른 창의 `ButtonStyle`은 어두운 남색/회색 표면과 얇은 테두리를 조금 밝혀, 마우스를 올리기 전에도 클릭 영역을 식별할 수 있게 했다. 글자색·붉은 호버/누름·선택 표시와 버튼 활성 조건은 유지한다. 타이틀에서 여는 저장소 창도 일반 창 스타일을 사용한다.

가독성 조정 검증: 에디터 빌드 성공. `Saved/ReviewRemediation/UITheme-Readability-20261020/index.json`의 관련 검사 21개 통과(20개 일반 성공, 1개 기존 엔진/백엔드 연결 경고 동반 성공), 실패·미실행 0개. 실제 PIE 캡처로 타이틀 홈 유지 및 다른 창 버튼 배경 변경을 확인했다. 재패키징은 하지 않았다.

3D 마네킹·조명·안개는 타이틀에만 존재한다. 데스크톱 런처와 서버 도우미의 화면, 게임의 피해·시야 VFX 및 SFX는 이번 변경 범위가 아니다.

## 유지되는 동작

- 버튼 연결, 서버 요청, 로그인 상태, 게임 규칙과 맵 이동 흐름은 바꾸지 않는다.
- 테마 적용은 입력 내용·비밀번호 마스킹·버튼 활성 여부·표시 여부를 변경하지 않는다.
- 오류·위험·접속 상태 등 의미가 있는 색상과 프로필 사용자 색상은 유지한다. 설문 답변 글씨는 기존 요구대로 흰색이다.
- 전체 화면 검정 페이드와 모달 배경은 기존 불투명도·계층을 유지한다. 페이지 프레임은 로비의 카운트다운·페이드·소셜 오버레이를 가두지 않는다.
- 정렬 순서와 메뉴 이동은 유지한다. 로비의 설문/환경설정만 공통 상단 도구줄에 나란히 배치했다. 오픈 매칭의 참가/코드 참가/새 방/뒤로/로그아웃 순서는 그대로다.

## 화면 크기 대응

로그인, 설정, 로비, 리더보드는 제한된 본문 폭과 공통 상단 강조선을 사용한다. 실제 뷰포트 DPI를 고려해 타이틀과 크기가 지나치게 달라지지 않게 맞춘다. 설정 탭은 좁으면 글자를 줄바꿈한다. 긴 일시정지 메뉴는 스크롤할 수 있고, 저장소 화면은 세 슬롯과 돌아가기 버튼이 함께 들어가도록 맞췄다.

## 새 UI를 추가할 때

- UMG: 버튼·입력창·콤보·체크박스에 `ProjectDFSDUI::Apply`를 사용한다. 초기 트리는 `ApplyTree`로 처리하되 동적 생성 항목은 생성 시 적용한다.
- 콤보 캡션의 전경색은 `UProjectDFSDComboBox` 생성자에서 지정한다. 기존 데이터와 이벤트는 기본 `UComboBoxString`과 동일하다.
- Slate: 공유 `ButtonStyle`, `InputStyle`, `ComboButtonStyle`, `RowStyle`와 색상 함수를 사용한다.
- 전체 화면 페이드/입력 차단 레이어에는 일반 버튼 스타일이나 페이지 폭 제한을 적용하지 않는다.

테스트를 위한 임시 계정 생성이나 데이터베이스 변경, 패키징·업데이트 게시는 실행하지 않는다. 실제 다중 PC 전체 흐름을 이 검사만으로 보증하지는 않는다.

## 폐백화점·낡은 사건 파일 질감 (2026-10-27)

- 바깥 배경의 매장·셔터·균열 장식은 제거했다. 공통 창은 누런 낡은 서류 색감을 유지하고, 버튼·목록·하단 프로필 바와 상점 진열대는 같은 따뜻한 회갈색 계열을 사용한다. 타이틀 장면이나 결과창으로 적용 범위를 확장하지 않는다.
- 사건 파일 가장자리에 물 얼룩·그을음·종이 섬유·작은 찢김과 접힌 모서리를 더한다. 저장소의 세 파일 표지에도 같은 처리를 한다. 서류 더미·테이프·추가 설명 문구는 배치하지 않는다.
- 상점의 기존 진열대와 상품 배치는 유지하며 선반의 녹·유리 긁힘과 낡은 황갈색 흔적을 더하며, 상품명·가격·구매/장착 버튼 위로 장식이 올라오지 않는다.
- 색상·질감은 그림 계층에서만 바뀐다. 내용 배치·입력·포커스·버튼 상태·스크롤·구매 처리·전체 화면 페이드에는 개입하지 않는다. 텍스트 대비와 기존 강조색을 유지한다.
- Slate 벡터 기하로 그리므로 외부 이미지나 머티리얼 자산을 추가하지 않으며 별도의 쿠킹 경로가 필요하지 않다. 고정된 시드와 제한된 정점 수를 사용하고 타이머·틱 애니메이션·화면 깜빡임은 추가하지 않는다.
- 손상 자국은 등간격·좌우 대칭으로 배치하지 않는다. 얼룩과 찢김의 수·위치·크기·농도를 달리하고, 파일 표지와 상점 상품 칸은 서로 다른 고정 시드를 사용한다. 한 화면을 보는 동안 손상 무늬가 매번 바뀌지는 않는다.

최종 검증: `WornCaseThemeBuild.log`의 Unreal Editor 빌드 성공. `Saved/FeatureChecks/WornCaseThemeQA/index.json`에서 관련 9개 검사 성공(일반 성공 8개, 기존 `r.MotionVectorSimulation` 엔진 경고를 동반한 타이틀 장면 검사 1개), 실패·미실행 0. 입력·비활성 상태·전체 화면 페이드, 결과창 프레임 제외, 타이틀 장면, 1280×720/800×600의 공통 메뉴·상점·저장소 배치를 확인했다. 화면은 `Saved/UIThemeQA`, `Saved/CaseRecordUIQA/Shop_*.png`, `Saved/CheckpointPreviewTests/SlotLayout-*.png`에 있다. 게임 패키징과 운영 데이터 변경은 하지 않았다.
