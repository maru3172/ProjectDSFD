# 게임 UI 공통 타이틀 테마

## 적용 범위

`ProjectDFSDUITheme.h/.cpp`가 타이틀에서 사용하던 반투명 어두운 버튼, 밝은 본문, 붉은 강조색을 공통으로 제공한다. 로그인·회원가입, 환경설정, 로비·방·매칭, 리더보드, 저장소, 일시정지·결과, 설문, 역할 가이드·튜토리얼, 친구·귓속말·신고·프로필, 음성 설정과 상호작용 안내에 연결했다.

3D 마네킹·조명·안개는 타이틀에만 존재한다. 데스크톱 런처와 서버 도우미의 화면, 게임의 피해·시야 VFX 및 SFX는 이번 변경 범위가 아니다.

## 유지되는 동작

- 버튼 연결, 서버 요청, 로그인 상태, 게임 규칙과 맵 이동 흐름은 바꾸지 않는다.
- 테마 적용은 입력 내용·비밀번호 마스킹·버튼 활성 여부·표시 여부를 변경하지 않는다.
- 오류·위험·접속 상태 등 의미가 있는 색상과 프로필 사용자 색상은 유지한다. 설문 답변 글씨는 기존 요구대로 흰색이다.
- 전체 화면 검정 페이드와 모달 배경은 기존 불투명도·계층을 유지한다. 페이지 프레임은 로비의 카운트다운·페이드·소셜 오버레이를 가두지 않는다.
- 정렬 순서와 메뉴 이동은 유지한다. 로비의 설문/환경설정만 공통 상단 도구줄에 나란히 배치했다. 오픈 매칭의 참가/코드 참가/새 방/뒤로/로그아웃 순서는 그대로다.

## 화면 크기 대응

로그인, 설정, 로비, 리더보드는 제한된 본문 폭과 공통 상단 강조선을 사용한다. 실제 뷰포트 DPI를 고려해 타이틀과 크기가 지나치게 달라지지 않게 맞춘다. 설정 탭은 좁으면 글자를 줄바꿈한다. 긴 일시정지 메뉴는 스크롤할 수 있고, 저장소 화면은 세 슬롯과 돌아가기 버튼이 함께 들어가도록 맞췄다.

## 새 UI를 추가할 때

- UMG: 버튼·입력창·콤보·체크박스에 `ProjectDFSDUI::Apply`를 사용한다. 초기 트리는 `ApplyTree`로 처리하되 동적 생성 항목은 생성 시 적용한다.
- 콤보 캡션의 전경색은 `UProjectDFSDComboBox` 생성자에서 지정한다. 기존 데이터와 이벤트는 기본 `UComboBoxString`과 동일하다.
- Slate: 공유 `ButtonStyle`, `InputStyle`, `ComboButtonStyle`, `RowStyle`와 색상 함수를 사용한다.
- 전체 화면 페이드/입력 차단 레이어에는 일반 버튼 스타일이나 페이지 폭 제한을 적용하지 않는다.

## 검증

`ProjectProject01.UITheme.Contracts`는 대비, 입력 포커스, 선택 스타일, 원래 타이틀 버튼 색, 비밀번호·비활성 상태와 전체 화면 페이드 보존을 확인한다.

`ProjectProject01.UITheme.RenderPages`는 1280×720 및 800×600에서 실제 프로젝트 DPI로 메뉴 페이지를 렌더링한다. 결과는 `Saved/UIThemeQA/`에 기록한다. 실제 PIE 타이틀→로그인→타이틀 전환 검사도 로그인 화면과 타이틀 화면을 캡처한다. 별도로 기존 저장소 미리보기 검사가 돌아가기 버튼의 화면 내 배치를 확인한다.

테스트를 위한 임시 계정 생성이나 데이터베이스 변경, 패키징·업데이트 게시는 실행하지 않는다. 실제 다중 PC 전체 흐름을 이 검사만으로 보증하지는 않는다.

2026-10-20 최종 확인: `ProjectDFSDEditor Win64 Development` 빌드 성공. `Saved/ReviewRemediation/UITheme-Complete-20261020/index.json`에서 관련 검사 21개 통과, 실패·미실행 0개다. 그중 실제 PIE 검사 1개는 기존 엔진 `r.MotionVectorSimulation` 경고와 꺼진 백엔드의 서비스 상태 조회 경고를 동반했다. 화면/배치 검사 실패는 없다. 중간 검사에서 발견한 저장소 돌아가기 버튼 넘침과 도구줄 글자의 불필요한 줄바꿈도 수정 후 재검증했다.
