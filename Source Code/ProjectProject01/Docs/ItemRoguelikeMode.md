# 아이템 로그라이크 모드

기준일: 2026-11-04. 설계 단계 문서다. 구현 완료를 뜻하지 않는다. 수치는 구현 후 조정한다.

## 1. 확정한 규칙 (사용자 결정)

- PvP 모드다. 오픈매칭과 랜덤매칭 모두에서 고를 수 있다. 랜덤매칭은 모드별로 대기열을 따로 쓴다. 300초 뒤 봇 채우기도 같은 모드 안에서만 한다.
- 경기 시작 때 화면을 암전한 채로 각자에게 카드 3장을 보여 주고, 1장을 고르게 한다. 모두 고르면 암전을 해제하고 경기를 진행한다.
- 다음 층에 도착할 때마다 같은 방식으로 다시 고른다. 맵이 3층이면 한 경기에 3번 고른다.
- 제한 시간은 20초다. 그때까지 고르지 않은 사람은 서버가 남은 카드 중에서 무작위로 정해 준다. 선택하는 동안 경기 시간은 멈춘다.
- 고를 때마다 새로고침을 1번 쓸 수 있다. 새로고침하면 3장을 모두 다시 뽑는다. 제한 시간은 다시 시작하지 않는다.
- 효과는 경기가 끝날 때까지 유지된다. 결과 화면에서 각자 고른 카드를 보여 주고 끝낸다. 다음 경기로 이어지는 것은 없다.
- 관전자는 결과 화면에서 모든 플레이어가 고른 카드를 본다.
- 일반 모드의 규칙은 바꾸지 않는다.

## 2. 카드 구성

카드는 두 종류를 섞은 하나의 묶음에서 뽑는다.

| 종류 | 생존자가 받는 카드 | 마네킹이 받는 카드 |
| --- | --- | --- |
| 내 아이템 | S01~S15 (나에게 적용) | M01~M15 (나에게 적용) |
| 상대 진영 버프 | B그룹 어픽스 (마네킹에게 줌) | A그룹 어픽스 (생존자 전원에게 줌) |

- 상대 버프는 기존 어픽스(`ProjectAffixes.h` A01~A10, B01~B10)를 그대로 쓴다. 신호와 공략, 봇의 대응은 이미 구현되어 있다. 상대가 받을 것 중에서 내가 가장 잘 상대할 수 있는 것을 고르는 카드다.
- 3장에는 아이템과 버프가 각각 1장 이상 들어간다(제안).
- 이미 가진 아이템과 이미 걸린 버프는 다시 나오지 않는다.
- 이 모드에서는 기존 봇전 어픽스 모드(마스터+, 주간 등)와 함께 쓸 수 없다.

## 3. 아이템 목록

모든 효과에는 상대가 알아볼 수 있는 신호, 상대의 대응, 그리고 약점이 있다. 표시는 실제 시야 안에서만 보이고 벽 너머로는 보이지 않는다. 깜빡이는 연출은 쓰지 않는다. 신호는 계속 켜져 있는 빛이나 짧은 소리로 낸다. 새 조작키는 넣지 않는다.

## 4. 서버 판정

- 카드는 데디케이티드 서버가 서버 난수로 뽑아 플레이어별로 저장한다. 클라이언트는 "보여 준 3장 중 몇 번째"와 "새로고침"만 보낸다.
- 서버가 거절하는 경우: 선택 단계가 아닐 때, 이미 고른 층, 범위를 벗어난 번호, 두 번째 새로고침, 시간이 지난 뒤, 관전자나 다른 사람 명의의 요청.
- 효과는 서버만 건다. 아이템은 플레이어 기록에, 상대 버프는 어픽스 런타임의 활성 목록에 더한다. 속도 변화는 기존 어픽스의 상한(감속 최대 30%, 가속 최대 25%) 안에서 합친다.
- 고른 기록은 층 전환 carryover로 넘기고, 재접속하면 다시 받는다. 경기가 끝나면 결과와 함께 보낸 뒤 버린다.
- 봇 자리는 서버가 대신 고른다. 기존 마네킹 AI는 바꾸지 않는다. 아이템은 수치 변경과 표시로만 건다.
- 백엔드는 모드 선택(방 설정, 랜덤매칭 대기열)과 입장 티켓의 모드 필드만 맡는다. 고른 카드는 백엔드에 저장하지 않는다.

## 5. 아직 정하지 않은 것

- 이 모드의 결과를 공식 전적·레이팅·리더보드에 넣을지. 제안: 커스텀 규칙처럼 비공식으로 처리.
- 3장에 아이템과 버프를 각각 1장 이상 넣는 규칙.

## 6. 구현 상태 (2026-11-04, 빌드 전)

- 정한 것: 새로고침은 고를 때마다 1번. 이 모드의 경기는 비공식이다(커스텀 규칙과 같은 필터, 리더보드 등록 버튼 숨김).
- 바꾼 것: M07 '검은 천'은 실루엣을 어둡게 할 재질 작업이 없어 '녹슨 태엽'(정지 몸체가 시선에서 풀린 직후 1초 +15%)으로 바꿨다. 소리 신호 일부(무전 잡음, 벨, 캔, 방독면 숨, 천 끌림)는 빛 표시(펄스)와 발소리 크기로 대신했다. 클라이언트 펄스가 최대 3초라 S11 발자국은 3초이고, S06과 S12 표시는 서버가 다시 보낸다. M04는 예비 동작 대신 공격 순간에 팔이 빛난다.
- 백엔드: `Game/MatchModes.cs`(IBackendModule, `PUT /api/rooms/current/match-mode`, 티켓 `matchMode`), 랜덤매칭 모드별 대기열(`Platform/RandomMatchmaking.cs`), 방 상태 `matchMode`.
- 게임: `ProjectItemRoguelike.h`(카드), `ProjectItemRoguelikeRuntime`(서버 선택·판정·carryover), `ProjectRoguePick`(선택 화면·입력 잠금), `ProjectAffixRuntimeItems.cpp`(아이템 효과), 로딩 게이트 대기, 결과 화면 카드 기록.
- 검사: `ProjectProject01.ItemRoguelike.Rules`, `ProjectProject01.ItemRoguelike.PickRender`. 아직 빌드와 실행을 하지 않았다.
