# 소급 기록의 "미확인"을 예전 세션 대화로 보충

## 요약
- **목표:** 기능 문서 68개로 자동 생성한 소급 기록에는 당시의 요청, 시행착오, 원인이 대부분 "미확인"으로 남아 있었다. 이 칸들을 예전 Claude·Codex 세션의 대화 기록으로 보충한다.
- **방법:**
  - 대화 기록에서 각 기능 문서를 쓰거나 고친 세션을 찾는다.
  - 그 구간의 사용자 발언 원문과 작업 세션이 보고한 원인·실패·결정을 뽑는다.
  - 뽑은 내용을 각 소급 기록 끝에 "대화 기록 확인" 절로 붙인다.
- **결과:**
  - 68개 중 65개에 붙였다. 사용자 발언과 보고 줄은 모두 1,414줄이다.
  - 3개(`Review*Draft`)는 대화를 찾지 못했다.
- **현재 상태:**
  - 완료. 커밋은 하지 않았다.
  - 붙인 내용은 원문을 발췌한 것이다. 표의 미확인 칸 자체를 고쳐 쓰지는 않았다.

## 9-2. 요청·범위
- **사용자 발언:** "예전 세션 대화 기록 검색해서 미확인 부분 채워줘"(2026-11-27). 앞서 "이건 우리끼리만 확인하고 보려는 용도라 다른 팀원한테는 공개하지 말자"고도 했다.
- **해석과 한계:** 자동 생성된 표 칸은 생성 스크립트를 다시 돌리면 덮어써진다. 그래서 표를 직접 고치지 않고, 스크립트가 보존하는 별도 절로 붙였다(`Tools/WorkLogs/generate-retro-logs.js:86-87`).

## 9-3. 흐름
1. 추출 스크립트 `extract-doc-evidence.js`가 대화 기록을 읽는다.
   - Claude: `~/.claude/projects/C--DSFD-ProjectDSFD-Source-Code/*.jsonl` 21개(1.6GB)
   - Codex: `~/.codex/sessions/**/*.jsonl` 47개
2. Write·Edit·패치 도구로 `Docs/<이름>.md`를 고친 세션 구간을 찾는다.
3. 구간 범위는 첫 편집 전 사용자 발언 6개부터 마지막 편집 뒤 다음 사용자 발언 전까지다. 그 안의 사용자 발언(최대 14개, 360자)과, 원인·실패·결정 관련 단어가 들어간 작업 세션 문장(최대 10개, 320자)을 뽑는다.
4. 결과를 `doc-evidence.json`(문서 71개)에 저장한다.
5. 붙이기 스크립트 `append-transcript-evidence.js`가 내용이 같은 구간을 하나로 합친다. 이어 쓰기·포크 세션이 같은 이력을 담고 있어서다.
6. 시스템 알림·요약 메시지를 빼고, 각 소급 기록 끝의 절을 새로 쓴다. 다시 실행해도 절이 하나만 남는다.

두 스크립트와 원본 사본은 세션 스크래치패드에 있다(재부팅하면 지워질 수 있음). 붙이기 전 원본은 `scratchpad/worklogs-before/`에 있다.

## 9-7. 검증
- **실행 결과:**
  - 소급 기록 68개 중 65개에 절이 붙었다.
  - 절이 두 번 들어간 파일은 0개다.
  - 남은 시스템 알림은 0줄이다.
- **눈으로 확인한 표본:** `2026-11-12_MailAndCoupons.md` 1개. 우편함·쿠폰 두 가지만 하자는 사용자 결정과, 출석·시즌을 미룬다는 발언이 실제로 들어간 것을 확인했다.
- **확인하지 않은 것:**
  - 나머지 64개의 발췌가 그 문서와 실제로 관련 있는지는 보지 않았다. 구간 안에 같은 시간대의 다른 작업 대화가 섞였을 수 있다.
  - 작업 세션의 보고 문장은 그 세션의 주장이고, 다시 검증하지 않았다.
