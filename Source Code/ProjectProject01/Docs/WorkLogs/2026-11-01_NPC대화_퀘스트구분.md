# NPC 대화(휴대폰 연출)와 퀘스트 구분

## 요약
- 목표: 메인 퀘스트 중간에 캘린·아테아 같은 NPC와 대화하는 단계를 넣고, 대화는 휴대폰을 들고 보는 듯한 창으로 보여 준다. 퀘스트를 메인·연계·서브로 나눈다.
- 결과: 휴대폰 대화 창(열기·닫기 연출, 선택지 1개 이상, 빨간 점 알림), 메인 퀘스트 장(탐사 등) 선택, 연계 퀘스트(캘린·아테아) 탭과 열람 알림. 휴대폰은 통신이 안 되는 백화점 설정에 맞춰 녹슬고 망가진 모습.
- 상태: 구현·렌더 테스트 완료. 커밋 `316ad6f`(Quest Calibration)·`3499183`(연계 열람 알림)에 포함.
- 과정 기록 한계: 이 작업 전반부는 대화 요약 이전에 진행되어 세부 시행착오 일부는 원본 대화 기록에만 있다(아래 "출처").
- 기록 이력: 2026-11-27 작성 후 파일이 폴더에서 사라져(원인 미확인) 같은 날 같은 내용으로 다시 만듦.

## 사용자 요구(원문 요지)와 결정
- "UI 아래에 NPC와 대화하기 아이콘, 누르면 기존 창 위에 핸드폰을 들고 보는 것처럼" → 로비 하단 아이콘 + 오버레이 휴대폰 창.
- "주인공 대화는 선택해서, 선택지가 여러 개거나 1개인 경우도" → 선택지 개수 가변.
- "그 인물 언급 이전에 그 NPC와 대화하기가 끼어 있게", "생존자 튜토리얼 완료와 생존자로 1회 플레이 사이에 캘린과 대화하기" → 메인 퀘스트 단계 순서 지정.
- "대화하려고 하면 아이콘에 빨간 점" → 읽지 않은 대화 표시.
- "메인 퀘스트도 탐사 말고 여러 개, 선택이 될 거라고" → 장(chapter) 목록에서 고르면 그 장의 단계가 펼쳐짐.
- "연계 퀘스트 아래는 캘린 / 아테아만 추가" → 연계 탭에 두 줄만.
- "깜빡거리는 건 없애", "금 간 것도 대화창을 방해하면 안 됨" → 깜빡임 효과 제거, 금은 상태 표시줄로 옮김.
- 선택 사항(AskUserQuestion 답): 로비 퀘스트 화면에 배치, 포인트는 상관없음, 기본 연출, 대사 초안은 AI 작성.
