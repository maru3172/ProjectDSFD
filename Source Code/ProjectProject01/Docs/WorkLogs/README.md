### 기능 문서별 소급 기록 (자동 재구성)

`Docs/*.md` 기능 문서 68개마다 `YYYY-MM-DD_<문서 이름>.md`(날짜 = 그 문서의 첫 커밋)를 만들었다. 각 기록은 원 문서와 그 문서를 바꾼 커밋에서 목표·결정·검증·남은 일을 뽑아 규칙 항목대로 나눈 것이다. 원 문서·커밋에 없는 당시의 가설·시행착오·대화는 **미확인**으로 표시했고, 성능 측정이 없으면 **정량 검증 미완료**로 표시했다. 상세 설계·수치는 원 문서가 기준이다. 목록은 [`index.json`](index.json).

- 다시 만들기: `node Source Code/ProjectProject01/Tools/WorkLogs/generate-retro-logs.js` 뒤 `generate-commit-index.js`. 스크립트는 파일을 지우지 않는다. `> 소급 작성:` 표시가 없는 파일은 건너뛰고, 자동 기록 안에 사람이 보탠 `## ` 절(예: `작업 세션 직접 기록`)은 다시 만들어도 끝에 그대로 남는다. 2026-11-27 첫 재생성 때 수동 `rm`으로 다른 세션의 기록 몇 개가 지워진 일이 있어 이렇게 바꿨다.
- 규칙 원문: [`RULES.md`](RULES.md).

## 이 목록의 범위
- 2026-11-27에 Claude가 한 대화 세션(2026-10-31~11-01 작업분)을 이 규칙에 맞춰 소급 작성했다. 커밋은 사용자가 했고, 같은 커밋에 다른 세션·팀원의 변경이 섞여 있을 수 있다.
- 그 밖의 작업은 위 표의 다른 기록과 "기능 문서별 소급 기록"(다른 세션이 작성)이 다룬다.
- 2026-11-27부터 모든 기록에 "의도 대비 달성도"(RULES.md 9-9-1)를 넣는다. 위 2026-11-01 손으로 쓴 기록 7개에는 반영했다.
