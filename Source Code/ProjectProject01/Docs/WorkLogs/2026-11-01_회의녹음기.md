# 회의 녹음기 (MeetingRecorder)

## 요약
- 목표: 회의를 음성(마이크 + PC 소리)과 텍스트로 남기고, PC에서 음성 인식(Whisper) 후 대화문·요약을 만드는 독립 Windows 도구. 이후 메모장, 기록 수정·삭제, 사진 넣기 추가.
- 결과: WinForms(.NET 8) 앱 `Tools/MeetingRecorder`. 자체 검사 21개 통과.
- 상태: 완료. 최초 도입 커밋 `0d09d24`·`0cbdc15`, 메모장·편집·사진 `3499183`(사용자 커밋).

## 요청과 결정
- "텍스트 기록은 메모장처럼, 레코더 안에서 기록 수정·삭제, 기록에 사진 넣기"(사용자).
- 결정:
  - 메모장은 회의마다 `memo.md`(마크다운)에 저장. 사진은 회의 폴더 `images/`로 복사하고 `![이름](images/파일)` 줄로 넣음. RTF 내장 이미지는 클립보드를 덮어쓰고 요약·내보내기에서 쓰기 어려워 기각.
  - 시간 기록(타임스탬프 메모)은 별도 탭으로 유지하고 줄마다 수정·삭제(Delete 키·두 번 클릭 지원).
  - 회의 삭제는 영구 삭제 대신 휴지통으로 옮김(복원 가능).
  - 요약·대화문을 손으로 고치는 `편집`/`저장` 추가. 시간 기록 파일(`notes.md`)은 시간 기록 탭에서만 고치게 함(자동 재생성되므로).
  - 메모장 내용도 대화문 본문과 요약의 "메모장" 칸에 포함. 메모만 있는 회의도 요약 가능.

## 구조
- `MeetingSession`: `Memo` 속성, `MemoFile="memo.md"`, `ImagesFolder="images"`. `MeetingImages`(파일 복사·붙여넣기 PNG 저장·메모의 사진 목록).
- `MainForm`: 왼쪽 탭(메모장 / 시간 기록), 선택한 회의에 메모장이 연결(`SyncEditor`), 입력이 멈추고 700ms 뒤 저장. 녹음·기록 중인 회의는 메모리 객체를, 나머지는 디스크에서 새로 읽어 저장해 다른 작업의 저장을 덮어쓰지 않게 함.

## 시행착오
- 버튼 한 줄 추가로 1000x720에서 회의 목록이 한 줄로 눌림 → 버튼을 3열 2줄, "작업 취소"를 맨 위 줄로 이동. 좁은 폭에서 글자 잘림 → 이름 단축(음성 인식, 가져오기, 폴더 열기).
- Bash의 python이 실행되지 않음(Windows 스토어 별칭) → Edit/perl/node로 수정.

## 검증
- `MeetingRecorder.exe --selftest`: 21개 PASS(새로 추가 6개: 빈 메모장은 파일 없음, 사진 복사·순서, 메모장 마크다운 저장, 대화문·요약 포함, 시간 기록 수정, 삭제).
- `--snapshot <png> 1000 720`으로 화면을 그려 배치 확인.
- 미수행: 실제 사람이 Ctrl+V 사진 붙여넣기·휴지통 이동을 눌러 보는 수동 확인.
