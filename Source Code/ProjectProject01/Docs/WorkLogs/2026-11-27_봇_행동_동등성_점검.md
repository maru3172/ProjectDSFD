# 봇 행동 동등성 점검 (플레이어가 할 수 있는 행동 = 봇도 할 수 있는가)

## 요약
- **목표:** "플레이어가 할 수 있는 모든 행동은 봇도 할 수 있다"(사용자, 2026-11-27)에 맞는지 전체를 점검한다.
- **방법:** 다음 출처에서 플레이어 행동 목록을 만들고, 봇 코드(`ProjectMatchBots.cpp`)에서 같은 기능을 쓰는지 대조했다.
  - 서버 요청 함수(`Server*_Implementation`) 25개
  - 입력 바인딩(생존자·마네킹)
  - 상호작용 액터 3종
  - 놀이터 규칙 24개
  - 아이템 로그라이크 기획
- **결과:**
  - 기본 경기의 이동·달리기·핑·엘리베이터·층 이동·마네킹 명령 휠 8개 동작은 봇도 쓴다.
  - 빠진 것: 방화셔터 닫기(생존자·마네킹 모두), 아이템 카드를 봇이 직접 고르기·다시 뽑기, 놀이터 규칙 대부분.
  - 추가 확인(2026-11-27 2차): 구조 모드는 봇이 전부 빠져 있다. 놀이터 손전등 규칙에서는 생존자 봇이 몸체를 얼릴 수 없다. 놀이터 어둠에서는 봇이 사람보다 멀리 본다. 마네킹 자유 카메라는 봇 쪽 정보가 오히려 더 많다.
- **현재 상태:** 점검만 했고 코드는 바꾸지 않았다. 어느 항목을 반영할지는 사용자가 정한다.

## 9-2. 요청·범위
- **사용자 발언:**
  - "플레이어가 할 수 있는 모든 행동은 봇도 할 수 있다라는 점이 제일 중요해 결국 그게 실전과 같은 경험이니까"
  - "한번 전부 다시 한번 검토해줘 … 전체적으로 꼼꼼히 전부 검토해서 보고해줘"
- **범위 변경:**
  - 처음에는 "아이템 로그라이크 카드 고르기, 다시 뽑기, 투표는 안 한다"고 했다.
  - 봇이 그 판에 들어오고 서버가 대신 고른다는 사실을 확인한 뒤, 이 항목도 포함했다("응 그게 맞을거 같아").
- **사용자 예외:**
  - 사람 옆 도우미 봇은 셔터를 조작하지 않는다.
  - 멀티플레이에서 셔터 열고 닫기에는 제한이 없다.
- **기존 설계에서 뺀 항목(사용자 합의):**
  - 음성 채팅(`Docs/BotHumanLikeness.md` "일부러 넣지 않은 것")
  - 구조 기능(보류)
