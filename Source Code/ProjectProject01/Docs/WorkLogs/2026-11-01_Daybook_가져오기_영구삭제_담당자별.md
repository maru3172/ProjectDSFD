## (1) 다른 도구 가져오기
- 요청: "Notion 등 다른 툴 이용/불러오기".
- 결정: 브라우저에서 zip을 풀어(fflate) 페이지마다 기록 하나를 만들고, 페이지에 보이는 사진만 첨부. 하위 페이지는 부모 기록 아래로 연결.
  - Notion 파일 이름의 32자리 id와 `_all`을 제거.
  - 데이터베이스는 `_all.csv` 하나만 표로 변환.
  - 페이지 링크는 글자로, 웹 링크는 유지.
  - Obsidian `[[위키 링크]]`·`![[사진]]` 처리.
- 대안: 서버 일괄 가져오기(`import`, 관리자 전용·백업 형식) 대신 기존 `create`·파일 업로드를 사용. 작성 권한만 있으면 되고 사진 첨부까지 처리할 수 있기 때문.
- 시행착오: 제목 정리 순서 오류(`_all`보다 id를 먼저 지워 `_all`이 남음) → 순서 변경 후 통과.
- 한계: 실제 Notion에서 받은 파일이 아니라, 형식을 본뜬 샘플로 검사함. HTML은 브라우저의 DOMParser가 필요해 Node 검사 대상에서 빠졌고, 브라우저에서 한 번 확인함.

## (2) 영구 삭제
- 요청: "휴지통에서 바로 삭제, 휴지통으로 안 가고 영구히 삭제", "둘 다 팝업".
- 조사(지울 범위): 기록을 가리키는 곳을 마이그레이션 전체에서 수집.
  - 기록과 함께 지움: 댓글, 활동, 체크리스트, 첨부, 선후 관계, 즐겨찾기, 확인 대상·확인, 대화방 읽음, 인수인계, 알림.
  - 연결만 끊음: 하위 기록, 반복 생성 표시(지우면 반복 업무가 다시 생성되므로), 잠금, 접속 상태.
- 위험과 대응:
  - Git 작업 폴더 내보내기가 지워진 행의 파일을 남기고, "받아온 자료 확인"이 지운 기록을 되살릴 수 있었음(코드 확인).
  - `purged_records` 테이블(마이그레이션 `0011`)에 지운 id를 남기고, 받아올 때 건너뜀.
  - 내보낼 때는 이 프로그램이 쓴 뒤 바뀌지 않은 파일만 폴더에서 지움. 바뀐 파일은 충돌로 보고.
- 확인 팝업:
  - 휴지통 기록 1회.
  - 휴지통 비우기 1회(개수 표시).
  - 휴지통 없이 바로 영구 삭제 2회.
  - 파일 1회.
- 권한: 기록 작성자나 관리자. 휴지통 비우기는 관리자만.
- 이력: 내용 없이 `entry_purged`(종류만)를 남김.
- 시행착오: 파일과 함께 지운 파일 메시지를 `purged_records`에 남기지 않아 되살아날 수 있던 빈틈 → 함께 기록하도록 수정.
- 한계: 이미 커밋된 Git 이전 기록과, 지우기 전에 만든 백업에는 내용이 남는다(문서에 안내).

## (3) 담당자별 업무
- 요청: "각 담당자마다 할 일·계획·목표 따로", "목표도 그렇게?", "진행률도".
- 구현: `app/assignee-board.tsx`.
  - 사람 선택 칩(나 먼저, 담당 미정 마지막). 위쪽에 남은 일·기한 지남·7일 안 마감·완료 개수.
  - 칸 3개(할 일·계획·목표). 끝나지 않은 일을 마감일 순으로 먼저, 완료는 접어 둠. 마지막 선택한 사람을 기억.
  - 목표·계획 진행률은 `목표와 계획` 카드와 같은 함수(`linkedWork`)로 계산해 두 화면의 숫자를 맞춤.
- 시행착오:
  - 빈 칸 문구 "맡은 목표이(가)"가 어색함 → 칸별 문구로 바꿈.
  - 좁은 폭에서 제목이 잘림 → 칸 최소 340px로 줄바꿈.

## 검증
- `npx tsx scripts/check-tool-import.ts` 12/12.
- `node scripts/check-purge.mjs` 15/15. 확인한 내용:
  - 지워지는 범위와 원본 파일 삭제, 하위 기록 유지.
  - 이력에 내용이 남지 않음.
  - Git 폴더에서 빠지고 다시 받아와도 되살아나지 않음.
  - 파일의 모든 버전 삭제, 휴지통 비우기 권한·범위, 404.
- 회귀: `check-standalone` 43, `check-standalone-extended` 30, `check-team-tools` 31, `check-contacts` 37.
- 브라우저(확인 팝업을 함수로 대신 응답):
  - 바로 영구 삭제는 팝업 2회를 확인했고, 둘째에서 취소하면 기록이 남음. 둘 다 예면 삭제와 함께 "영구 삭제했습니다" 알림.
  - 휴지통 비우기 문구와 결과(휴지통 비어 있음) 확인.
  - 담당자별 숫자: 운영자 남은 4·지남 1·7일 1·완료 1.
  - 목표 "알파 빌드" 50%(연결 2개 중 1개 완료).
- 미수행: 여러 PC가 같은 Git 폴더를 쓰는 상황, 실제 Notion 내보내기 파일.
