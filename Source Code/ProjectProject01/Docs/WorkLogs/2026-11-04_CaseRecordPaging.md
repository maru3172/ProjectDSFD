## 요약
- 목표: 사건 보관함을 '사건 기록(로어)'과 '지난 날의 기록(지난 시즌 배틀패스 이야기)'로 나누고 배틀패스를 독립 탭으로, 페이지를 넘길 때 화면이 튀지 않게.
- 원인: 페이지 이동마다 본문 전체를 다시 만들어, 누른 버튼이 새로 생기며 눌림→보통→호버로 튐.
- 해결: 넘김·분류 전환·조각 선택 시 해당 영역만 다시 그림. 버튼·쪽수는 유지.

## 조사·시행착오
- 1차 가정: 새 글자의 첫 프레임 줄바꿈 높이 오류 → 새 본문을 숨겨 두 프레임 배치 후 교체(`BeginBodyRebuild`) 구현. 사용자 영상에서 해결 안 됨.
- 영상 1/30초 프레임 차분: 화면 전체 이동이 아니라 누른 버튼만 바뀜 → 원인 확정. `BeginBodyRebuild`는 코드에 남음(효과 없음).
- 역할 선택 검사(`Frontend.InitialTutorialAndRandomRole`): 모드 콤보 갱신을 잠시 빼도 실패 → 무관. 임시 진단 출력으로 `Records->IsWriting()=1` 확인. 다른 작업이 넣은 튜토리얼 건너뛰기의 메인 퀘스트 쓰기가 서버 없는 검사에서 끝나지 않아 역할 선택이 '저장 중'으로 멈춤.
