# Daybook 협업툴: 독립 실행·발표 자료·내보내기·가져오기·초대 (초기 구축분)

## 요약
- 목표: 팀 협업툴 Daybook을 유료 호스팅 없이 운영자 PC에서 돌리고, 팀원은 프로그램 실행만으로 쓰며, 자료는 Git으로 공유하게 만든다.
- 이 기록의 범위: 이번 대화 세션에서 진행한 협업툴 작업 중 대화 요약 이전 부분.
  - 디스코드를 뺀 3가지 기능.
  - 파워포인트처럼 쓰는 발표 자료와 .pptx 내보내기.
  - 여러 번 다시 보고 복사할 수 있는 초대 코드와 오른쪽 아래 초대 팝업.
  - 텍스트·Word·Excel·CSV·PDF 내보내기.
  - 사진·ppt·md·txt·word 가져오기.
  - 서버 시작·승인 안내.
  - 자료 폴더를 `%LOCALAPPDATA%` 대신 저장소 안에 두어 GitHub로 공유.
- 결과(당시 검사): 독립 실행 43, 확장 30, 문서 가져오기 8, 폴더 내보내기 18, 해시 대체 경로 14입력·UUID 1,000개 검사 통과.
- 상태: 완료. 커밋 `0d09d24`·`0cbdc15`(사용자 커밋, 다른 작업도 함께 포함).
- 과정 기록 한계: 대화 요약 이전 작업이라 세부 판단 과정은 일부만 복원했다. 원본 대화 기록 위치는 아래 "출처".

## 사용자 결정(확정 범위)
- 다른 두 팀원은 서버 운영 없이 프로그램 실행만으로 로컬 작성·저장. 공동 서버는 운영자가 켤 때만.
- 오프라인 변경은 Git 커밋·받아오기 후 "받아온 자료 확인"으로 반영. 서버 재접속으로 자동 덮어쓰지 않음.
- Git 자료와 로그인·승인·권한은 분리. Git 자료를 받았다고 접근 권한이 생기지 않음.
- 유료 호스팅·API를 운영 필수 조건으로 쓰지 않음. 자동 Git 커밋·푸시 없음. 클라우드 데이터 영구 삭제는 명시 확인 전 하지 않음.

## 구조
- 독립 실행: Node 런타임과 SQLite, 파일 저장소, 자체 인증(`self-host/*.mjs`), Windows 런처(`self-host/launcher`, .NET).
- 화면: `app/*.tsx` (React, vinext 빌드). 패키지는 `node self-host/package.mjs` → `outputs/Daybook-Windows`.

## 시행착오(요약 시점에 기록된 것)
- FeatureChecks의 Player 튜플 형식 불일치 → 수정.
- 설정 파일 상위 탐색(FindUp)이 현재 폴더를 빠뜨림 → 포함.
- 날짜 검사 `validDay`가 NaN 날짜를 통과 → 거부.
- `git status`가 하위 폴더 파일을 묶어 보여 줌 → `-uall`, 한글 경로가 깨짐 → `core.quotepath=false`.
- 붙여넣은 `git status` 줄의 앞 공백이 사라져 상태 판정이 틀림 → 공백 없는 형식도 처리.
- 슬라이드 썸네일 크기 계산을 컨테이너 기준(cqw)으로 수정.
- Esc가 업무 관리 창까지 닫음 → 수정.
