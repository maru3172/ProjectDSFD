## 실패·조사·해결 과정

1. PowerShell npm.ps1 실행 정책 차단을 사용자가 보고했다. npm.cmd run install:ci 실행 방법으로 안내했다.
2. npm 설치의 DNS ENOTFOUND가 발생했다. 승인된 네트워크 실행에서 재설치했다. 설치 중 esbuild 부재·Next 타입 부재가 발생했고 설치 완료 후 타입 검사 통과했다.
3. Git 검사 await를 동기 transaction 콜백에 넣어 features.mjs가 SyntaxError: Unexpected reserved word로 시작 실패했다. 사용자가 배포 실행 로그를 제공했다. 비동기 검사를 transaction 밖으로 이동하고 membership 확인을 유지했다. ue5List GET 허용 누락도 수정했다.
4. 번들 빌드만으로 서버 시작을 보장하지 못한 실패였다. package.mjs에 서버 모듈 import 검사를 추가하고, 배포 동봉 Node로 임시 서버 시작·인증·공간 생성·UE5 목록 HTTP 검사를 통과했다.
5. 첫 HTTP 검사는 origin 헤더 누락으로 403이었다. 정상 origin 요청으로 재검사했다. 초기 로컬 연결 EACCES도 승인된 실행에서 재검사했다.
6. 임시 Git 저장소 생성은 .git/config 권한 오류로 실패했다. 실제 프로젝트의 읽기 검사에서 상태·빌드 점검·원격 접근 제한을 확인했다.
7. 패키징의 Node 라이선스 다운로드가 DNS ENOTFOUND로 실패했다. 승인된 네트워크 실행으로 배포를 완료했다.
8. PowerShell 문자열 편집과 JSX 따옴표 구문 오류를 고친 뒤 재검사했다. 포트폴리오 초기값의 TypeScript 변환 오류는 명시적 필드 초기화로 해결했다.
9. 초기 연결 동선이 어렵다는 사용자 지적에 따라 해당 탭 내부 생성·연결 동선을 구현했다. 실제 시간 절약 효과는 측정하지 않았다.
