# 서버 운영 UI 버튼 검사 실패 수정 — 개발 기록

## 요약

- 목표: `ServerAdministrationUiChecks`의 "기존 서버 운영 버튼 18개 모두 보존·중복 없음" 실패 원인을 찾고 고친다.
- 원인(확인): 커밋 `3dcf47f`(2026-10-30)에서 `콘텐츠·소통`에 버튼 2개(`시즌 뽑기 상품·확률`, `메인 퀘스트·스토리`)가 추가됐지만 검사의 예상 목록은 2026-10-27 이후 갱신되지 않았다.
- 해결: 예상 목록에 두 버튼 추가, 개수 비교를 고정값 18 대신 목록 길이로 변경.
- 결과: 서버 운영 UI 검사 106개 통과. 커밋 `d0de20f`에 포함.

## 문제·증상·재현 (9-4)

- 발견 계기: 기본 기록 작업 중 도우미 오프라인 검사를 돌리다 실패를 봤다.
- 기대: 검사 통과. 실제: `System.InvalidOperationException: 기존 서버 운영 버튼 18개 모두 보존·중복 없음`(`ServerAdministrationUiChecks.cs` 22행).
- 재현: `dotnet ProjectProject01FeatureChecks.dll --server-administration-ui-checks <출력 폴더>`.
- 심각도: 낮음(기능 정상, 검사만 실패). 다만 회귀 검사가 막혀 다른 실패를 가릴 수 있어 수정.
