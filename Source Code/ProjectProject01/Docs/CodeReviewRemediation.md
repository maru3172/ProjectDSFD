### F08 저장 방식

세 개의 **논리 저장소**는 유지한다. 각 저장소는 `_GenerationA`/`_GenerationB`에 번갈아 쓰며, 현재 가장 최신인 정상 세대를 다음 쓰기 대상으로 사용하지 않는다. revision은 시계가 뒤로 바뀌어도 증가한다. 새 파일은 길이와 본문 CRC를 통과한 뒤에만 Unreal 역직렬화 및 기존 상태 무결성/버전 검사를 받는다. 완성된 정상 세대만 선택하므로 중단된 다음 쓰기가 마지막 정상 저장을 덮어쓰지 않는다. 이는 단일 파일 rename 대신 세대 선택으로 논리적 커밋을 구현한 것이다. 저장 장치 자체의 전체 고장/전원 손실까지 보장한다는 뜻은 아니다.

기존 primary/backup 및 v1~v6 저장은 읽고 보존한다. 최종 저장 형식은 v7(AI 상태 추가)이며 구버전 미리보기도 유지한다. 최근 플레이 시각은 `_Recent`에 따로 기록해 불러오기 때문에 월드 스냅샷을 재작성하지 않는다. 최근 시각 파일이 망가지면 저장 당시 시각으로 돌아갈 뿐 게임 상태를 잃지 않는다. 미리보기 데이터도 본문과 분리 검증해 이미지만 손상되면 게임 상태는 계속 읽는다. 삭제/새 게임은 해당 논리 저장소의 구버전/교대 세대/최근 시각 파일을 함께 정리한다.
