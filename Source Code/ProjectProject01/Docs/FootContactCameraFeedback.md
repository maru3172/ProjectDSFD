# 발 디딤 연동 카메라·발소리

2026-10-19 요청. F01~F30/C01~C08 개선 작업은 다시 지시할 때까지 보류한다.

- 싱글 플레이어와 멀티의 활성 생존자 소유 시점에만 적용한다. 멀티 마네킹의 공유/직접 조작 시점은 적용하지 않는다.
- 기존 발소리 컴포넌트가 유효한 디딤을 확정한 시점에 카메라 연출도 시작한다. 독립 사인파를 돌리거나 별도 발걸음 타이머를 추가하지 않는다. 발소리 최소 간격, 거리 기반 걷기/달리기 판정, 거리·차폐 감쇄는 유지한다.
- 걷기는 1.3cm, 달리기는 1.6cm 아래로 내려갔다 원래 높이로 돌아온다. 2026-10-20 요청으로 걷기만 직전 1.0cm에서 30% 늘렸다. 한 번의 전체 길이는 각각 0.32초/0.26초이며 앞 28% 동안 내려가고 나머지 시간에 복귀한다. 새 디딤이 겹쳐도 현재 높이에서 이어가며 누적 낙폭은 없다.
- 정면의 벽을 볼 때도 걷는 느낌을 내기 위한 같은 디딤 곡선의 미세한 하향 Pitch는 걷기 0.13도/달리기 0.20도다. 오른발은 10% 강한 0.143도/0.22도다. 걷기 회전도 직전 0.10도에서 30% 늘렸고 달리기는 유지했다. 원래 시선으로 부드럽게 복귀하고 연속 디딤/걷기·달리기 전환 시 현재 각도에서 이어간다. 좌우 회전(Yaw)·좌우 기울기(Roll)·좌우 이동·FOV 변화는 없다.
- 오른발은 왼발보다 카메라 낙폭 10% 증가(1.43cm/1.76cm). 발소리는 오른발 피치 배율 0.90을 유지한다. 한 쌍에 동일한 작은 피치 변동을 사용해 무작위 변화가 오른발 차이를 상쇄하지 않게 했다. 이번 변경에서 소리·음량은 바꾸지 않았다.
- 발소리의 좌우는 기존 자동 디딤/Notify가 확정된 순서대로 왼발부터 교대한다. 스켈레톤 발 본을 새로 검출하는 기능은 아니다. 플레이어·파트너·마네킹 발소리 모두 같은 좌우 피치 규칙을 쓰되 파트너의 기존 50% 음량과 마네킹 근거리 관절음은 유지한다.
- 화면 흔들림 설정이 0이면 카메라 연출은 완전히 꺼지고, 중간값은 그만큼 줄어든다. SFX 음소거와는 독립적이다. 피격·사망 카메라, 점프/낙하, 관전, 결과 화면, 비소유 Pawn, PIE 탑뷰에서는 출력하지 않는다.
- 카메라 컴포넌트나 Pawn/Controller를 움직이거나 회전시키지 않고 최종 `CalcCamera`의 화면 Z와 Pitch에만 가산한다. 입력 시선에 각도를 누적하지 않는다. AI 시야·충돌·이동·사망 카메라의 기준 좌표에는 영향을 주지 않는다.

자동 검사는 `ProjectProject01.Player.FootContactCamera`. 진폭/시간/복귀/오른발 비율/접근성, 실제 `CalcCamera` 출력, 중복 디딤, 음소거, 역할·수명 조건을 확인한다. 실제 플레이 체감과 멀미 여부는 개인차가 있으므로 별도 확인이 필요하다.

- 걷기만 낙폭 1.0→1.3cm, 미세 하향 회전 0.10→0.13도로 조절했다. 오른발 10% 차이, 달리기 1.6cm/0.20도, 원위치 복귀 시간과 접근성·역할 제한은 유지한다.
