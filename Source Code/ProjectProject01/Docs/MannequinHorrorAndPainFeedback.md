# 마네킹 공포 음향·피격 호흡·피해 화면 (2026-10-18)

기존 30개 보완·8개 확인 작업은 사용자 지시에 따라 중단 상태다. 이번에는 후속 요청한 아래 연출만 변경한다. AI 행동·승패·데스카운트·무적 시간·화면 전환과 심박의 원래 인지/거리 계산은 유지한다. 후속 요청에 따라 심장박동·호흡·하트비트 VFX의 최고 강도 유지/완화 표현을 함께 적용한다.

## 마네킹만 무게감과 몸체 소리 추가

- 현재 단단한 바닥의 플라스틱 착지음은 유지하고 78→54Hz의 낮고 짧은 충격 성분을 얇게 더한다. 운동화 소리·파트너 50% 음량·기존 발 착지 간격은 유지한다.
- 후속 요청으로 기존 관절·몸체 합성음을 별도 `UPlasticJointSynthComponent` 3D 출력으로 분리했다. 음색·발생 확률은 바꾸지 않는다. 새 발걸음이 나와도 이미 시작된 짧은 삐걱임은 재시작하거나 끊지 않는다. 반복 루프나 별도 전역 배경음은 추가하지 않는다.
- 움직이면서 지면에 있을 때만 시도한다. 발 착지 또는 누적 약 40도 방향 변경을 계기로 시도하며, 소환 시 처음 1.5~3.5초는 쉬어간다. 정지·공중·운동화 스타일·데디케이티드 서버에는 새 관절 소리가 생기지 않는다.
- 걷기는 2.8~5.2초 간격에 32%, 달리기는 1.8~3.6초 간격에 55%, 이동 중 방향 전환 시도는 72% 확률이다. 실패해도 다음 간격까지 쉬어 매 프레임 재시도하지 않는다. 시간은 현재 게임 월드 기준이며 이미 시작된 소리의 짧은 잔여분은 정지 직후 끝날 수 있다.
- 발 착지 0.025~0.075초 뒤 작고 낮은 플라스틱 비틀림을 0.16~0.32초 재생한다. 달리는 경우 몸체가 작게 흔들리는 성분을 보탠다. 음량은 원래 FootstepVolumeScale의 16~22% 배수다.
- 관절·달리기 몸체 마찰음은 1m 안에서 거리 기준 원래 음량, 1~4m 선형 감쇄, 4m 이상 무음이다. 발소리의 낮은 착지 충격은 기존처럼 30m부터 60m까지 거리 감쇄한다. 양쪽 모두 기존 SFX 분류와 실제 표면 기준 벽 차폐(음량 25%, 저역 통과 600Hz)를 유지한다.
- 관절 출력은 마네킹 루트를 따라다닌다. 발 착지 트레이스로 발소리 컴포넌트가 바닥으로 이동해도 관절 출력은 바닥 안으로 이동하지 않는다. 마네킹마다 최대 한 개를 지연 생성하고 재사용하며, 재생 후 유휴 정지 및 소유 발소리 컴포넌트 종료 시 정리한다. 데디케이티드 서버에는 만들지 않는다.
- 각 클라이언트의 표현용 확률이며 생존자 탐지나 서버 AI 명령에는 영향을 주지 않는다. 사용자 정정에 따라 실물 녹음을 새로 찾거나 다운로드하지 않고 이미 만든 합성음을 그대로 사용한다.

## 비치명적 피격

현재 합성기 기준 흐름:

- 0.00~0.34초: 짧고 거친 고통 반응.
- 0.34~0.85초: 무음.
- 0.85~1.27초: 첫 날숨, 이후 0.38초 쉼.
- 1.65~2.07초: 두 번째 날숨, 이후 0.38초 쉼.
- 2.45~2.87초: 세 번째 날숨, 이후 0.50초 쉼.
- 3.37~4.02초: 짧게 숨을 고르는 마지막 한숨.

후속 청취 요청에 따라 호흡 진폭만 최초 버전의 40%로 줄인 뒤, 피격 신음보다 조금 작게 해 달라는 요청으로 추가 20%를 줄여 현재 32%다(직전 대비 약 -1.94dB). 고통 신음 자체의 음량은 줄이지 않았다. 각 날숨은 0.68→0.42초, 마지막 한숨은 1.60→0.65초로 줄였고, 사이의 무음은 유지했다. 전체 반응은 5.75→4.02초다.

호흡에서 일정한 음정의 비중을 줄이고 여과된 숨소리를 중심으로 바꿨다. 추가 피격 강도는 기존대로 커지지만 쉬는 간격을 빠르게 만들지 않는다. 새로운 피격/사망은 기존처럼 해당 합성기의 반응을 다시 시작한다. 사용자의 실제 말소리 녹음이나 전문 성우 연기가 아니므로 자연스러운 발음·감정 재현에는 한계가 있다.

## 사망

- 후속 청취 요청으로 긴 개방형 비명을 제거했다. 낮고 거친 `으윽!`을 의도한 0.38초 단일 신음으로 끝낸다. 높은 음정으로 치솟는 부분과 긴 비명 유지 구간은 없다. 기존 사망 카메라·암전·쓰러짐 SFX의 시간은 변경하지 않았다.
- 비치명적 피격의 3회 호흡·마지막 한숨을 사망 뒤에는 재생하지 않는다. 기존 쓰러짐 시점의 월드 SFX, 거리·벽 차폐 및 사망 후 감쇄를 유지한다.

## 평상시 심박 연동 호흡

- 사용자 정정에 따라 상시 기본 호흡은 제거했다. 기본 진입은 기존 `HeartbeatRange` 안에 위협이 있고 실제 심박이 활성일 때만 생존자 로컬 시점에서 시작한다. 위협 구간을 겪지 않은 평상시에는 출력하지 않는다. 아래 달리기 최고 강도 유지·이탈 후 완화·안도 한숨은 별도 예외다. 마네킹·파트너·다른 생존자의 숨소리로 네트워크 전파하지 않는다. 기존 피격 신음·피격 후 호흡의 3D 전파와 감쇄는 바꾸지 않는다.
- 기존 심박 계산의 실제 CurrentBPM과 DataTable의 BaseMinBPM, BaseMaxBPM, EncounterMaxBPM을 정규화해 연동한다. 자체 적 감지를 추가하지 않으며 심박수 계산과 조우 후 감쇠 규칙도 바꾸지 않는다. 낮은 위험도의 초입은 한 호흡 주기 약 3.5초를 유지하지만, 근접 상황이 너무 느리다는 후속 요청으로 높은 위험도는 약 0.55초까지 단축했다(직전 최대 1.8초). 주기마다 약간의 차이를 주며 심박 하나마다 호흡을 다시 시작하지 않는다. 기본 설정의 평상시 추격 상한 120 BPM에서도 충분히 빠르게 나오도록 하고, 드문 165 BPM 조우 상승에만 의존하지 않는다.
- 강도는 0.5초 정도로 부드럽게 따라가며, 강할수록 소리가 커지고 공기 마찰과 떨림이 거칠어진다. 활성 초입의 합성 진폭 배수는 0.008, 최대 긴장은 0.15이며 강도에 1.4 지수를 적용해 초입에는 아주 작게 올라온다. 상시 호흡은 없고 SFX 음량 설정을 따른다.
- 후속 요청으로 평상시 호흡만 둥근 `후우`가 아닌, 입을 연 짧은 `하아`를 의도한 개방형 공명으로 변경했다. 한 주기에 `하아` 한 번만 내며, 높은 위험도에서는 다음 주기가 빨리 이어져 `하아, 하아, 하아`가 된다. 소리는 약 0.52초(초입)~0.22초(긴박), 다음 주기 간격은 약 3.5~0.55초다. 고위험 구간은 더 짧고 강한 진입·거친 공기 마찰·불규칙한 떨림을 더한다. 발성 중인 호흡을 재개/중복하지는 않되, 갑자기 위험해지면 이미 끝난 호흡 뒤의 긴 무음 대기를 줄여 반응한다. 피격 신음·피격 후 회복 호흡·사망 신음, 최고 강도 유지/진정/안도 한숨 규칙은 변경하지 않는다. 합성 음색이므로 실제 발음의 자연스러움은 청취 확인이 필요하다.
- 피격 즉시 심박 연동 호흡을 정지한다. 4.02초 피격 반응 전체 및 합성기 실제 재생이 끝난 뒤, 그때의 위협/달리기 최고 강도 유지/진정 상태에 맞게 이어간다. 평상시 기본 호흡을 다시 켜지는 않는다. 추가 피격은 대기 종료 시각을 연장하고 사망은 복귀를 차단한다. 사망·탈출·결과·관전·로비·타이틀 및 비소유/데디케이티드 서버에서는 시작하지 않는다. 싱글 저장 불러오기는 호흡 억제 상태만 초기화하며 기존 심박 인지 기록을 새로 변경하지 않는다.

### 위협 구간별 공통 연출 규칙

- 기존 `HeartbeatRange` 내에 남아 있는 마네킹 수로 진입/이탈을 판정한다. 한 적에게서 멀어져도 다른 적이 범위 안에 있으면 이탈이 아니다. 별도 감지 트레이스나 서버 AI 판정은 추가하지 않는다.
- 달리는 동안에는 해당 구간에서 경험한 최고 BPM·호흡 강도·하트비트 VFX 거리/밀집도 강도를 유지한다. 위험이 더 커지면 최고값을 갱신한다. 범위 밖에서도 안에서 시작한 달리기가 계속되면 같은 최고 강도를 유지한다.
- 범위 안에서 달리기를 멈추면 최고값 고정을 풀고 현재 실제 위험도 수준으로 서서히 낮춘 뒤 유지한다. 무음/완전 투명으로 강제 전환하거나 안도의 한숨을 내지 않는다.
- 범위 밖으로 걸어 나가거나, 안에서 시작한 달리기를 밖에서 마치면 약 2초 동안 심장박동·긴장 호흡·일렁임/현기증 VFX가 함께 잦아든다. 그 뒤 약 0.95초의 작은 안도 날숨을 한 번만 내고 끝낸다. 이미 출력된 VFX 강도부터 내리므로 진정 시작 시 화면 강도가 갑자기 튀지 않는다.
- 밖에서 달렸다 멈추는 것만으로는 새 긴장 호흡이나 안도 한숨이 생기지 않는다. 한숨은 위협 진입→이탈 한 구간당 한 번이다. 진정 중 재달리기는 보류 중인 같은 구간의 최고 강도를 다시 유지하고, 재접근은 진정과 한숨을 취소한다.
- 피격 신음/회복 호흡이 우선이다. 한숨 예정 시점에 피격 반응이 남아 있으면 종료 후 안전한 상황에서만 출력한다. 사망·결과·관전·타이틀·로컬 소유권 상실 및 초기화는 예약/최고값을 폐기한다.
- 심박의 원래 인지·거리·조우/감쇠 계산은 내부 원본으로 유지한다. 실제 박동 간격·강도와 `GetCurrentBPM`/`IsHeartbeatActive`는 위 공유 연출 상태를 반영한다. 하트비트 VFX의 머티리얼/접근성 배수는 그대로이고, 피격 시 붉은 VFX와 서버 피격 보호 시간은 이 규칙으로 바꾸지 않는다.

## 피해 VFX

- 빠르게 들어오고 천천히 물러나는 기존 Intro/Fade 타이밍과 MaxOpacity/MaxThickness 설정을 유지한다. 기본 0.1초 진입·2초 해제다.
- 기존 중앙 타원 시야 구조는 유지하며 경계를 약간 더 안쪽으로 눌러준다. 안쪽의 옅은 적색에서 바깥쪽의 어두운 혈색까지 부드럽게 연결하고, 균일한 빨간 판 대신 아주 미세한 비대칭을 준다. 중앙은 투명하게 남긴다.
- 겹치는 사각 면 대신 연결된 단일 타원형 메시로 그린다. 화면 모서리까지 정확하게 연결하고 번쩍임·새 카메라 흔들림·흐림은 추가하지 않는다.
- 기존 접근성의 VFX 강도 및 화면 번쩍임 감소 배수를 적용한다. 배수가 0이면 표시하지 않으며, 연출 시간이나 서버 데스카운트 보호 시간은 바꾸지 않는다.
- 데카 감소 단계에 따른 강화: 첫 차감의 기준 연출에서 데카 0까지 불투명도 1.0→1.3배(상한 1.0), 테두리 두께 1.0→1.35배로 점진적으로 강화한다. 기본 3회 기준 차감 후 남은 2/1/0은 불투명도 0.70/0.805/0.91, 최대 두께 150/176.25/202.5px다. 중앙 시야는 남기며 지속적인 빨간 화면·추가 번쩍임·새 흔들림은 넣지 않는다.
- 서버가 차감 직후 Remaining/Starting 기준으로 강도를 계산해 소유 클라이언트 Reliable RPC에 함께 보낸다. 클라이언트의 데카 복제를 기다리거나 누적 피격 횟수로 추정하지 않는다. 싱글·멀티·파트너 실제 밀침 차감에 공통 적용하며 최종 사망은 최대 강도다. 체크포인트 회복·불러오기는 다음 차감 시 실제 남은 데카를 기준으로 자동 재계산한다.
- 기존 신음·숨소리도 서버가 계산하는 데카 감소 비율에 따라 강도·떨림이 증가한다. 추가로 줄인 호흡 음량은 모든 단계에 같은 배수로 적용하므로 이 단계별 강화는 유지된다. 호흡 템포와 쉬는 간격, 사망 시 호흡 없음은 유지한다.
