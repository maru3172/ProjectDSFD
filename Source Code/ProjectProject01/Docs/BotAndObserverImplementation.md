# 5단계 봇·오픈매칭 관전 구현 기록

## 확정한 구조

적응형 유틸리티 + HFSM + 아군 감각 공유 + 경로 위 Steering + 관측 패턴 통계 기반 온라인 적응.
신경망, Q-learning, 강화학습, 외부 AI 서비스 및 실행 중 모델 훈련은 사용하지 않는다.

난이도는 1 쉬움 / 2 보통 / 3 어려움 / 4 전문가 / 5 마스터다. 단계 정규값 `(L-1)/4`의 제곱으로 기본 능력 곡선을 만든다. 단계 자체는 경기 중 바꾸지 않는다. 1~2만 확률적 이탈/기회 제공이 있으며, 상위 단계도 반응·기억·적응 강도 제한을 지킨다. 실제 체감 난이도는 플레이 테스트로 조정해야 한다.

의도적인 유인과 상대의 회전 습관을 역이용하는 제한적 심리전은 **4~5단계 전용**이다. 1~3단계의 기본 시야 대응·추격·일반 우회·협력은 유지하지만, 유인 행동은 점수나 허용 마스크가 높아져도 실행할 수 없다. 경기 중 누적 통계로 이 제한을 해제하지 않는다.

## 실제 구현 위치와 제한

- `ProjectAdaptiveBotPolicy.h`: 엔진/월드 접근이 없는 공통 판단 코드. 상대 위치를 직접 조회할 수 없다.
- `ProjectMatchBots.cpp`: 실제 경기 전용 서버 실행 어댑터. 서버 보증 로스터를 읽고 생존자 몸체·마네킹 명령·공격·로딩·경기 결과에 연결한다.
- 기존 싱글 AI와 튜토리얼/연습 AI는 유지한다. 후속 요청에 따라 연습모드의 적응형 opt-in 연결과 난이도 선택 UI는 제거했다. 이전 `AdaptiveBots`/`BotDifficulty` URL도 연습 AI를 바꾸지 않는다.

### 통계와 감각

최근 60초를 5초짜리 12개 구간으로 고정 저장한다. 실제 관측 시간, 정지·달리기·시선·회전 방향 비율을 집계한다. 오래된 구간은 가중치가 감소하고 60초 이후 제외된다. 여러 관측자가 같은 상대를 봐도 0.19초 이내 동일 대상 표본은 중복 집계하지 않는다. 관측이 없는 시간은 정지/방어 증거로 추가하지 않는다. 신뢰도는 유효 관측 시간 2~16초 범위에서 상승한다.

감각 공유는 팀별로 분리하며 출처·대상·관측 시각·당시 위치/속도를 담는다. 고정 16개 저장소를 사용하고 만료/미래 시각/비정상 값은 거부한다. 기억 상한은 난이도별 2.5~8초다. 이 정보는 마지막 관측 위치이지 현재 숨은 상대 위치가 아니다.

### 유틸리티 적응

고정 전술 후보(탐색·압박·좌/우 우회·유인·엄호·재집결·회복·관찰·대기)의 기본 점수를 계산한다. 관측한 방어 성향이 높으면 압박 점수를 낮춘다. 4~5단계에서는 추가로 유인·우회 점수를 올리고, 회전 성향이 우회 방향에 작은 편향을 준다. 낮은 단계도 눈앞의 위협에 반응하는 기본 적응은 수행한다.

영향은 `난이도별 적응 상한 × 관측 신뢰도`로 제한한다. 변경값은 시정수 2초의 지수 보간으로 반영하고 점수는 0~1.1로 제한한다. 행동 선택은 난이도별 집중도를 가진 가중 확률 방식이다. 반응 간격과 행동 허용 마스크는 점수와 별도로 강제한다. 이것은 관측 통계에 대한 직접적인 공식 갱신이지 보상 최적화나 강화학습이 아니다.

### HFSM과 이동

부모 상태는 중단/활성/종료다. 그 아래 대기·정지·탐색·교전·재배치·지원·회복을 둔다. 경기 종료와 시선 정지는 전술의 유지 시간보다 우선한다. 실제 공격 시 거리·LOS·시선 정지 상태를 다시 확인한다.

대상 기억이 만료되거나 아군이 사라지면 결정 유지 타이머가 남아도 기존 공격/지원 전술을 재검토한다. 보이지 않는 대상의 실제 위치를 복사하거나 기억 시간을 갱신하지 않는다. 대기/회복 전술은 직접 이동으로 실행하지 않는다.

Steering은 이미 구한 경로의 진행 방향에 제한된 횡방향 분리를 더한다. 역주행이나 새 경로를 만들지 않고 진행 방향 대비 횡보정은 최대 0.3이다. 실제 캡슐 충돌/내비게이션 검사는 엔진 어댑터가 담당한다. 기존 회피 알고리즘을 중복 활성화하지 않는다.

## 검증 현황

- 같은 공통 코드의 독립 C++ 검사: 1,066개 통과 (4~5단계 전용 제한·기억 만료·아군 보정 포함).
- Unreal 자동 검사 `ProjectProject01.Bots.AdaptivePolicy`, `TrustedRoster` 제공.
- 격리 HTTP/MySQL 검사: 봇전 167개, 관전 16개(친구 초대 정원/수락 포함) 및 기존 운영/소셜/랜덤매칭/결과복구 검사 통과. UE 프로세스는 대역이므로 실제 네트워크 클라이언트 입장 검증과 구분한다.
- 엔진 검사 26개 통과: `Saved/AdaptiveBotChecks/Repro-20261023-162131-e755f9fa/index.json`. 실제 경기 게임 모드에서 양 역할 × 5단계, 관전 자유시점/고정시점, 연습 장애물 ON/OFF, 기존 튜토리얼/연습 AI 및 로비 UI를 검사했다. 이후 관전 종료 결과/페이드 및 엘리베이터 연결을 보강했으므로 최신 검사 결과를 다시 확인해야 한다.
- 초기 opt-in 프로토타입의 PIE 18개 시나리오 통과 기록은 `Saved/AdaptiveBotChecks/Repro-20261023-125220-6bacd42e/index.json`에 보관한다. 이후 연습모드에 새 난이도를 적용하지 말라는 요청으로 연결·관련 검사는 제거/교체했다. 이 과거 결과는 현재 실제 봇전이나 벽·엄폐물 검증을 의미하지 않는다.
- 실제 서버 봇, 매칭/레이팅/관전 연동과 외부 PC/패키징 검사는 아직 완료되지 않았다.
- 운영 DB 변경·게임 패키징 없음.

### 인간 플레이어와 같은 팀인 봇

실제 경기 어댑터가 같은 생존자 팀의 인간 동료를 확인한 경우에만 `HumanAlly` 보정을 준다. 상대 봇의 단계·능력과, 연습모드의 적 AI는 그대로다. 보정은 선택한 단계를 바꾸거나 이동 속도·피해량을 조작하지 않는다.

- 발견 후 반응과 판단 주기를 약간 늦춘다(기본의 1.25배).
- 엄호 점수는 최대 0.36으로 제한하고 관찰보다 재집결을 조금 선호한다.
- 인간을 대신한 유인 전술은 선택하지 않는다.
- 2~2.5초 연속 엄호/관찰 후에는 반응 간격에 비례한 휴지기를 두어 완벽한 상시 방어를 피한다. 바로 앞 위험에는 자기 방어를 허용한다.
- 일부러 죽기·길막·명령 무시를 추가하지 않는다. 플레이어가 핵심 공략을 담당하면서도 동료로서 도움이 되는 방향이다. 재미와 실수 빈도는 실제 플레이로 조정해야 한다.

### 별도 봇전 연결 작업

매칭 선택에 별도의 봇전 버튼과 역할/5단계 선택 UI, 인증된 `/api/bot-matches`와 서버 보증 봇 로스터를 추가했다. 봇은 로그인 계정이나 EOS 음성 자격 증명을 받지 않는다. 경기 확정 시 역할/난이도를 동결하고 게임 서버의 일회용 티켓 검증 응답으로만 전달한다. 임의 클라이언트 URL로 봇을 추가하지 않는다.

격리 MySQL(23307)에서 봇전 HTTP/DB 검사 167개 및 기존 통합 검사가 통과했다. 실제 게임 모드의 PIE 실행도 별도로 검사했다. 다만 HTTP 검사의 게임 프로세스는 대역이며, PIE 검사가 외부 PC/패키징/실제 맵 전체의 공략 가능성을 증명하지는 않는다. 운영 설정 `Bots:EnableDedicatedMatches`, `Bots:EnableOpenObservers`는 검증 중 기본 비활성화이며, 운영 서버 재시작이나 DB 적용은 하지 않았다.

오픈매칭 방장만 봇 추가/삭제/개별 난이도 변경이 가능하다. 인간+봇을 합쳐 경기 인원은 3명이다. 별도 봇전은 로그인한 인간 1명과 봇 2명이며, 인간 역할을 선택할 수 있다.

랜덤 매칭은 솔로 대기자만 사용한다. 300초 전에는 인간 3명을 기다리며, 이후 부족한 1~2자리만 봇으로 보충한다. 살아 있는 검색의 최장 대기는 900초이고 기존 세션 생존 확인을 유지한다. 반대 역할의 서버 검증 레이팅으로 봇 수준을 선택하고 매치 확정 시 고정한다. 역할별 Elo 초기값 1200, K=24, 범위 400~2400이며 중복 결과 제출은 한 번만 반영한다. 구간은 `<850 / <1100 / <1350 / <1650 / 그 이상`이다. 이것은 AI의 통계 적응과 별개의 매칭용 실력 추정이다.

### 난이도별 실제 차이

| 단계 | 기본 판단 간격 | 관측 기억 상한 | 통계 적응 상한 | 행동 특성 |
| --- | --- | --- | --- | --- |
| 1 쉬움 | 약 1.65초 | 2.50초 | 0.04 | 기본 탐색·추격·시야 대응. 판단 시 24% 탐색 이탈 기회 |
| 2 보통 | 약 1.57초 | 2.84초 | 0.07 | 기본 협력·우회가 조금 증가. 탐색 이탈 기회 12% |
| 3 어려움 | 약 1.34초 | 3.88초 | 0.16 | 협력·엄호·일반 우회 강화. 고의적 유인/습관 역이용 없음 |
| 4 전문가 | 약 0.95초 | 5.59초 | 0.31 | 실제 관측한 방어/회전 습관에 대한 제한적 유인·우회 편향 허용 |
| 5 마스터 | 약 0.40초 | 8.00초 | 0.52 | 같은 규칙 안에서 가장 빠른 판단·감각 공유·전술 조합. 만능 지식/즉시 반응 없음 |

판단 간격에는 0.85~1.25배의 변동이 있다. 공격·이동 속도·피해·시야 규칙은 원래 게임 규칙을 따른다. 단순히 시간이 지났다고 단계를 올리지 않으며, 유효한 관측이 축적될 때만 상한 내 점수가 바뀐다. 기억이 만료되면 숨은 상대를 계속 따라가지 않는다. 인간 동료 보정은 위 표와 별도로 적용한다.

### 오픈매칭 관전

경기 3자리와 별도로 관전자 2자리다. 기본 입장은 경기 참가이며, 경기 자리가 찼을 때만 빈 관전 자리로 들어간다. 대기방의 본인 전환·방장의 타인 전환/강퇴를 제공한다. 봇과 관전자를 로그인 계정인 경기 참가자로 위조하지 않는다.

기본은 모델 없는 자유 비행이다. 좌측 시점 패널에서 전체/참가자 3명 선택, 시선 고정 여부를 고른다. 우측 경기 상황 패널은 별도이며 각각 접을 수 있다. 고정 시선은 시각 표시 전용 10Hz 전송으로, 이동/공격/AI 판정에 사용하지 않는다. 상태 패널은 2Hz 갱신한다. 관전자의 음성·준비·전적/레이팅·공격 권한은 없다.

맵 전환은 기존 전체화면 암전/확인 절차에 관전자도 포함한다. 엔진의 컨트롤러 교체 시 관전자 유형을 유지한다. 경기 종료 시 보고 있던 사망 연출이 남으면 마친 뒤 암전하고, 불투명한 결과 배경 위에서 결과 내용만 드러낸다. `경기가 종료되었습니다.` 아래 마네킹과 생존자 두 명의 경기 성공/실패·포획·구출·탈출 기록을 모두 표시한다. 관전자 자신의 전적이 아니며 누적 계정 전적을 별도로 조회하는 기능은 아니다.

### 연습모드 실전형 환경

새 5단계 봇과 분리한다. 기존 연습 AI를 그대로 쓰면서 `실전형 벽·엄폐물 배치`를 체크하고 `인원 적용 / 다시 연습`을 눌러 적용한다. 역할을 전환해도 이 선택을 전달한다. 기본은 꺼짐이다.

연습용 맵에만 런타임 구조물을 배치한다. 두 코너 벽과 전시대형 섬 엄폐물이 시야 차단·우회·양쪽 견제를 만들며, 중앙 경로를 단순 직선이 아닌 우회 경로로 바꾼다. 바닥 지지, 기존 물체 충돌, 스폰/탈출 목표 예약 영역을 검사하고 유효한 조각만 배치한다. 동적 NavMesh와 실제 충돌/Visibility를 사용한다. 맵 원본을 덮어쓰거나 실제 경기/싱글 맵을 수정하지 않는다.

재미·공정한 실수 빈도·유저가 공략하는 체감은 기능 검사만으로 증명하지 않는다. 장애물 OFF/ON과 같은 난이도에서 아군 보정의 유무를 비교 플레이하여 판단해야 한다.
