# 미니게임 기획안

로비의 녹슨 휴대폰 안 `오프라인 게임` 폴더에서 짧게 즐기는 미니게임 5종이다(생존자 쪽 4, 마네킹 쪽 1). 모두 본편의 규칙인 "보고 있으면 멈추는 마네킹"을 다른 방식으로 쓴다. 백화점 안은 통신이 안 된다는 설정이라 오프라인 게임으로 둔다. 긴 매칭 대기(300초·900초) 동안 할 거리를 주는 것이 목적이다.

## 처음 하는 사람을 위한 안내
- 새 판은 시작 카드부터 연다: `목표 / 조작 / 요령` 세 줄과 `시작 (스페이스)` 버튼. 한 칸씩은 1스테이지에서만 띄운다. 같은 세 줄이 카운트다운과 일시정지 화면에도 나온다.
- 화면 안에 지금 할 일을 적는다. 정전 복구: 방 왼쪽 아래 `할 일: ...`, 배전반·퓨즈 이름표. 한 칸씩: 상태줄 둘째 줄 한 문장(붙잡힘 → 되돌리기, 바로 앞이 문 → 셔터, 노란 테두리 마네킹이 멈춘 이유), 문 칸에 `문`.

## 게임

| 게임 | 재미 | 한 판 | 조작 |
| --- | --- | --- | --- |
| 움직였다 | 관찰력 | 1~2분 | 마우스(클릭으로 고르기), 스페이스·Enter: 확인 |
| 정전 복구 | 긴장감·주의 분배 | 60~90초 | WASD(설정한 이동 키)·방향키 이동, 마우스 손전등, F·오른쪽 클릭 손전등 켜고 끄기 (퓨즈는 배전반 앞에 서 있으면 저절로 끼워짐) |
| 한 칸씩 | 묘수풀이식 턴제 퍼즐 | 스테이지당 1~3분 | WASD/방향키 이동, Q/E 제자리 돌기, 스페이스 셔터, Z 되돌리기, R 처음부터, 마우스로도 가능 |
| 어디서 났지? | 청각 | 1분 안팎 | 8방향 칸 클릭 또는 W/E/D/C/X/Z/A/Q(숫자패드 8/9/6/3/2/1/4/7), R 다시 듣기 |
| 다가가기 (마네킹) | 타이밍·참을성 | 30~60초 | 설정한 앞으로 키·위 방향키·스페이스·마우스 누르고 있기 |

### 움직였다
- 백화점 통로 사진에 마네킹이 서 있다. 정해진 시간(3초 + 마네킹당 0.25초) 동안 기억하고, 불이 2초 꺼졌다 켜지면(부드럽게 어두워졌다 밝아짐, 깜빡임 없음) 몇 개가 자리·고개·팔을 바꿔 있다. 움직인 마네킹을 모두 골라 확인(스페이스)한다.
- 알아보기 쉽게: 마네킹마다 옷 색이 다르다(12색, 전후 같은 색). 고개는 정면(눈 둘)·왼쪽·오른쪽(옆얼굴, 코가 나옴), 팔은 내림·만세·오른팔 뻗기. 배경은 어둡게 깔아 인물이 앞에 선다.
- 라운드 n: 마네킹 min(4+n, 12)개, 바뀌는 수 1개(4라운드부터 2개, 8라운드부터 3개), 옆걸음 폭 max(70, 160-8n)(너비 1000 기준, 최소 7%: 잔걸음이 아니라 분명한 한 걸음).
- 정확히 맞혀야 통과(라운드 점수 100+25n). 틀리면 목숨 하나를 잃고 다음 라운드로. 목숨 3개.
- 배치는 서버가 판마다 정한 시드로 만들고 정답은 보내지 않는다. 채점도 서버가 하며 같은 라운드는 두 번 채점하지 않는다.

### 정전 복구
- 정전된 전기실(340×500)을 위에서 본다. 손전등(반각 27.5°, 거리 230) 빛에 닿은 마네킹은 멈추고, 어둠 속 마네킹만 다가온다(플레이어 95, 마네킹 36). 시작할 때 2개, 14초마다 하나씩 최대 5개.
- 바닥의 퓨즈 3개를 밟아 줍고, 배전반 앞(44 이내)에 서 있으면 1.6초에 하나씩 저절로 끼운다(키 없음). 끼우는 동안은 빛이 배전반에 고정된다. 3개를 끼우면 성공.
- 신호: 어둠 속에서 움직이는 마네킹은 2.5초 동안 서서히 사라지는 발자국을 남긴다(화면 깜빡임 없음). 대처: 손전등(F 또는 오른쪽 클릭으로 켜고 끔). 약점: 켜 둔 동안 배터리가 초당 2.4% 줄고, 다 닳으면 다시 켤 수 없다.
- 마네킹은 빛 속에서나 바로 옆(46 이내)에 있을 때만 보인다.

### 한 칸씩
- 칸 맵에서 출구까지 간다. 한 칸 걸으면 그쪽을 보게 되고, 걷거나 셔터를 내릴 때마다 마네킹도 모두 나에게 한 칸 다가온다(읽는 순서대로, 가로 거리가 크면 가로부터).
- 내가 보는 직선 위의 첫 마네킹은 움직이지 못한다. 벽·내린 셔터·마네킹이 시야를 막는다.
- 제자리에서 돌기는 무료다. 행동 수에 들어가지 않고 아무것도 움직이지 않는다.
- 방화 셔터는 바로 앞의 문(X)에만, 스테이지마다 정해진 횟수만큼 내린다. 내린 셔터는 벽이 된다.
- 스테이지 10개(1~3, 5, 7: 셔터 없음 / 4, 6, 8: 1개 / 9, 10: 2개). 기준 수는 풀이기가 찾은 최소 행동 수이고, 셔터 스테이지의 최단 풀이는 셔터를 쓴다. 검사(`MiniGameChecks`)가 모든 스테이지를 다시 풀어 확인한다.
- 별: 기준 수 이하 3개, 기준 수+3 이하 2개, 그 밖 1개. 되돌리기(Z)는 자유롭게 쓸 수 있고 최종 수순만 서버가 다시 둬 본다.
- 규칙 코드는 서버(`Tools/ProjectProject01Backend/Game/MiniGameRules.cs`)와 게임(`Source/ProjectProject01/Private/ProjectMiniGameRules.cpp`)에 같은 내용으로 있고, 양쪽 검사가 같은 수순으로 확인한다.

### 어디서 났지?
- 어둠 속에서 마네킹 관절이 삐걱거린다. 소리가 난 방향을 8방향(45° 간격, 앞부터 시계 방향) 중에서 고른다. 라운드마다 한 번 다시 들을 수 있다.
- 소리는 스테레오로 놓인다. 좌우는 크기와 두 귀 사이의 짧은 시간 차(최대 0.6 ms)로, 앞뒤는 뒤쪽 소리를 더 먹먹하게(저역 통과)·조금 작게 해서 구분한다. 이어폰을 권한다.
- 라운드 n: 소리 크기·길이가 점점 줄고(하한 있음), 3라운드부터 다른 방향의 가짜 소리(배관 두드림·셔터 덜컹) 하나, 6라운드부터 둘. 가짜 소리는 진짜보다 약간 크게 낸다(크기만으로 고르지 못하게).
- 목숨 3개, 통과 점수 100+20n. 방향은 서버가 판마다 정한 시드로 정하고 채점도 서버가 한다.

### 다가가기 (마네킹)
- 내가 마네킹이 되어, 등을 돌린 생존자에게 다가간다(거리 0→100, 초당 12). 키를 누르고 있는 동안만 움직인다.
- 신호: 생존자가 돌아보기 전에 어깨가 움찔하고 숨을 들이쉰다(0.55초). 이어서 손전등을 켜고 돌아본다(소리 포함).
- 대처: 멈추기. 돌아보는 동안(돌기 시작 0.12초 뒤부터) 움직이면 들켜서 25 밀려나고, 세 번 들키면 끝난다.
- 약점: 가까워질수록 돌아보는 간격이 짧아지고, 35 이후로는 돌아보는 척만 하는 경우가 섞인다(15~35%). 너무 오래 멈추면 기록이 늦어진다.
- 순위: 걸린 시간(짧을수록), 같으면 들킨 횟수(적을수록). 서버는 8초보다 짧은 기록을 받지 않는다.

## 휴대폰 화면
- 게임을 열면 휴대폰이 0.5초 동안 손에서 돌리듯 가로로 커져 화면 가운데로 온다. 상태줄의 `가로/세로` 버튼으로 바꾼다. 저절로 세로로 돌아가는 것은 경기 시작과 로그아웃뿐이다.
- 휴대폰 바깥을 누르면 휴대폰이 우측 하단에 작게(30%) 접힌다. 어두운 배경이 걷히고 뒤의 화면을 쓸 수 있으며, 진행 중인 게임은 키보드 포커스를 잃어 멈춘다. 작은 휴대폰을 누르면 다시 커진다. 완전히 닫는 것은 `닫기`·Esc.
- 소리는 모두 코드로 만든다(쿡할 에셋 없음). UI 음량을 따른다.

## 일시정지와 이어하기
- 자동 정지: 매칭이 잡혀 경기 시작, 로그아웃·계정 변경, 휴대폰 창 닫기, 게임 종료, Esc.
- 계정·게임마다 진행 중인 판 하나를 서버에 저장한다. 멈출 때와 라운드·단계가 끝날 때 저장한다. 다른 PC에서도 이어한다.
- 다시 열면 `이어하기 / 새로 시작`. 이어하면 3초 카운트다운 뒤 시작한다.
- 멈춘 동안 게임 화면을 가린다(배치를 멈춰 놓고 연구할 수 없음). 멈춘 시간은 기록에 넣지 않는다.

## 리더보드
경기 리더보드와 별도. 게임마다 `주간 / 전체`, 내 순위 표시.

| 게임 | 순위 기준 | 서버 검증 |
| --- | --- | --- |
| 움직였다 | 도달 라운드, 같으면 점수 | 배치 생성·채점을 서버가 한다 |
| 정전 복구 | 성공 시간(짧을수록), 같으면 남은 배터리 | 서버가 판 시작을 기록, 불가능하게 짧은 기록 거부 |
| 한 칸씩 | 스테이지별 최소 이동 수, 전체는 별 합계 | 이동 기록을 서버가 다시 돌려 확인 |
| 어디서 났지? | 통과 라운드, 같으면 점수 | 방향 생성·채점을 서버가 한다 |
| 다가가기 | 걸린 시간(짧을수록), 같으면 들킨 횟수 | 서버가 판 시작을 기록, 8초 미만 거부 |

## 조작 충돌 방지
- 게임 창에 포커스가 있을 때만 입력을 받는다. 로비 단축키·채팅·캐릭터 조작과 서로 새지 않는다.
- 이동(WASD)·상호작용(E)은 플레이어가 설정에서 바꾼 키를 따른다.
- 경기가 시작되면 게임을 멈추고 입력을 즉시 놓는다. 경기 중에는 열리지 않는다.

## 보상
- 게임별 최고 기록과 순위. 포인트는 주지 않는다(대기 중 반복으로 재화를 쌓는 통로 방지).
- 업적과 꾸미기 보상은 아직 넣지 않았다(다음 작업).

## 구현 위치
- 서버: `Game/MiniGames.cs`(API·저장·순위), `Game/MiniGameRules.cs`(규칙·스테이지·풀이기). 표 `minigame_runs`(계정·게임마다 열린 판 하나), `minigame_scores`(주간 `YYYY-MM-DD`·전체 `all`).
- API: `GET /api/minigames`, `POST /api/minigames/start|save|spot/answer|listen/answer|finish|abandon`, `GET /api/minigames/leaderboard?game=&board=&period=weekly|all`.
- 게임: `UProjectMiniGames`(서버 통신, 로그아웃·맵 이동 때 멈추고 저장), `ProjectMiniGameWidgets.cpp`(휴대폰 안 화면), `ProjectMiniGameRules.cpp`(규칙).
- 검사: `MiniGameChecks`(격리 DB, `Run-IsolatedIntegration.ps1 -FrontendOnly`), `ProjectProject01.MiniGames.*`(규칙·화면 렌더 → `Saved/MiniGameQA`).

## 화면
- 휴대폰 화면 안에서만 그린다. 대화창·다른 UI와 겹치지 않는다. 화면 깜빡임을 쓰지 않는다.
