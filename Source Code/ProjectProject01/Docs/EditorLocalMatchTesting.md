# 127.0.0.1 에디터 실매칭 테스트

패키징 없이도 에디터 클라이언트에서 실제 백엔드의 오픈 매칭·랜덤 매칭을 거쳐 경기에 입장한다. 경기 맵만 강제로 여는 우회가 아니다.

## 준비

1. 최신 백엔드 코드로 서버 도우미의 백엔드를 재시작한다. 로컬 MySQL·운영 자격 설정은 기존 도우미 설정을 사용한다.
2. Unreal Editor를 새 빌드로 실행하고, 클라이언트 환경설정의 서버 IP를 `127.0.0.1`로 설정한다. 백엔드 주소는 `http://127.0.0.1:5080`이다.
3. 에디터의 클라이언트 창 3개에서 서로 다른 계정으로 로그인한다.
4. 오픈 매칭은 같은 방에 들어가 준비 후 시작한다. 랜덤 매칭은 각 클라이언트가 따로 시작하여 3명을 모은다.

로비 요청 시 에디터 모듈이 같은 PC의 운영 자격으로 백엔드에 에디터 서버 실행 경로를 설정한다. 대기 중에는 게임 서버 프로세스가 없고, 실제 경기 세션이 필요할 때 현재 엔진의 `UnrealEditor-Cmd.exe`를 서버 모드로 실행한다. 에디터에서 저장한 맵과 컴파일된 프로젝트 DLL을 사용하므로 서버 재패키징은 필요 없다.

이미 운영자가 활성화한 서버 구성이 있다면 이를 덮어쓰지 않는다. 패키징 서버 대신 에디터 서버로 전환하려면 기존 경기를 종료하고 도우미에서 게임 서버 운영을 중지한 뒤 PIE를 다시 시작한다. 기본 로컬 테스트 동시 경기 수는 1개, 게임 서버 포트는 UDP 17777부터 사용한다.

테스트 후 패키징 서버로 운영할 때는 도우미에서 게임 서버 운영을 중지하고 기존 패키징 서버 설정으로 다시 시작한다. 에디터 실행 경로는 백엔드의 실행 중인 운영 구성일 뿐 소스 INI나 배포 설정에 저장하지 않으며, 백엔드 재시작 시 초기화된다.

## 유지되는 검증

- 백엔드 로그인, 방·랜덤 대기열, 카운트다운, 서버 준비 heartbeat 확인
- 실제 세션의 방·매치·포트 및 역할 검증
- 서버 준비 이후에만 일회용 접속 티켓과 암호화 키 발급
- 게임 서버의 티켓 소비·접속 허가 검증

자동 준비는 **에디터 PIE + 정확한 루프백 백엔드 주소**에서만 사용한다. 운영 자격을 읽고 서버를 설정하는 구현은 에디터 모듈에만 있으며 패키징에 포함되지 않는다. 패키징된 클라이언트는 입력한 서버 주소의 실제 서버 준비와 접속 허가가 필요하다.

백엔드가 꺼져 있거나 운영 자격이 없으면 안내 후 실패한다. 확인 요청과 설정 요청은 각각 5초 제한이며, 서버 프로세스의 준비도 기존 제한 시간 안에만 대기한다. 정지된 서버를 준비된 것처럼 위장하지 않는다.

## 이번 UI·조작 변경

- 환경설정 → 접근성 → 카메라 셰이킹 활성화. 비활성화해도 기존 흔들림 강도는 보존한다.
- 마네킹 Z/X/C/Q/B는 직접 조작하지 않아도 사용 가능. 시점 선택 상태의 명령은 즉시 적용되고, 직접 조작 중 Z/X/C는 조작 해제 후 수행한다.
- 상태창을 `현재 상태`와 `명령 상태`로 분리한다. 직접 조작 중에는 현재 상태를 `직접 조작`으로 유지하고 별도의 명령 상태에서 정찰·추격·추종·정지를 보여준다. 상태 및 입력 안내에서 `직접 조작 해제 후…` 유형의 표기는 사용하지 않는다. 이동·직접 공격은 직접 조작 상태가 필요하다.
- 튜토리얼의 이동/달리기 목표는 현재 거리와 필요 거리를 m 단위로 표시한다. 기본 생존자 걷기 10m·달리기 20m, 마네킹 이동 10m이며, 표시된 목표를 채우면 추가 연습 시간 없이 다음 단계로 넘어간다. 기존 맵의 예전 기본값 8m·12m는 실행 시 새 기본값으로 갱신하고 다른 사용자 지정 거리는 유지한다.
- 랜덤 매칭 대기 표시는 남은 제한 시간이 아니라 시작 버튼을 누른 뒤의 경과 시간이다. `0분 59초 → 1분 00초`처럼 증가하고, 취소 후 새로 시작하면 초기화된다. 서버 폴링이나 PC 시계 변경으로 타이머가 되돌아가지 않으며 기존 서버의 180초 만료 안전장치는 유지한다.

테스트 명령: `Tools/ProjectProject01FeatureChecks/Run-IsolatedIntegration.ps1 -EditorServerExecutable '<현재 엔진>/Binaries/Win64/UnrealEditor-Cmd.exe'`. 이 검사는 포트 23307 및 검증 전용 데이터 경로를 확인한 뒤에만 실행하고, 테스트 서버는 종료한다. 운영 DB는 사용하지 않는다.
