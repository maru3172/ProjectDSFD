## 경험치·레벨 보상·미션 변경

개인 기록과 좌측 하단 프로필에 현재 레벨 구간의 경험치 바를 표시한다. 레벨 100에서는 가득 찬 상태를 유지한다. 기본 구간 보상은 5레벨마다 `100 + 레벨 × 10` 기록 포인트이며, 25·50·75·100레벨에는 기념 프로필 테두리도 지급한다. 개별 받기/모두 받기는 서버 영수증으로 중복 지급을 막는다. 레벨과 매칭 실력 레이팅은 별개다.

일일/주간 미션은 봇전과 PvP를 별도로 집계한다. 미완료 칸만 변경 가능하며 기본 비용은 **칸별 일일 10→20→30… / 주간 50→100→150… 포인트**다. 서버가 가격을 결정하고, 같은 변경 횟수의 동시/재전송 요청은 한 번만 차감한다. 변경 시 새 미션의 진행은 0부터 시작한다. 목표를 달성한 칸은 아직 보상을 받지 않았어도 변경할 수 없고, 보상을 받은 칸도 다음 초기화까지 다시 채워지지 않는다. 한국 시간 일일 00시 / 주간 월요일 00시에 진행도·완료 잠금·변경 횟수를 새 기간으로 전환한다. 이전 기간의 지연된 변경 요청은 거부하여 새 미션에 비용을 쓰지 않는다.

배틀패스 상단은 다음 두 줄이다. 실제 사건 날짜를 아직 지정하지 않았으므로 자리표시자를 유지한다.

```text
[RECORD 0] 202X-XX-XX 18:24:01 _OMINOUS ENTRY
(~ 정식 출시 전까지)
```

## 조사 기록 확정 규칙

일일/주간 미션과 조사 기록은 별개다. 조사 기록은 총 13파트이며 각 파트에 1~9조각을 배치한다. 현재 파트의 9조각을 모두 발견해야 다음 파트가 열린다. 조각별 고정 위치는 실제 맵의 `ProjectCaseInvestigationRegion.RegionId`와 서버 구성의 `Region`을 일치시켜 연결한다. 기존 맵 바이너리에 임의의 117개 위치를 배치하지 않았다. 실제 조사 위치와 사건 내용은 콘텐츠 작성자가 지정해야 한다.

하루 수집 제한은 없다. 주간 기본 수집 가능 수량은 15개이며 한국 시간 월요일 00시를 기준으로 새 주간 사용량을 계산한다. 미사용 주간 수량을 이월하지 않는다. 운영자가 도우미의 **서버 운영 → 사건 기록 조사 수량**에서 15~117개로 직접 조정할 수 있다. 수량을 올려도 기존 발견·수령·이번 주 사용량을 초기화하지 않는다. 시즌 말 증가량은 자동으로 정하지 않는다. 시즌 종료 후 수량을 0으로 만드는 자동 처리도 없다.

**지난주 공개분을 시즌 종료까지 누적 보관한다는 제안은 취소되었다.** 모은 조각 자체와 파트 완료 기록은 유지한다. `[RECORD 0]`의 사건 발생 시각은 이야기 표기이며 수집 한도 계산에 사용하지 않는다. 실제 시각은 아직 제공되지 않았다.

도우미의 **117조각 문구·위치 연결 구성**은 전체 구성을 편집/게시한다. 총 117개가 모두 유효하고 ID/파트/조각 번호가 중복되지 않아야 게시된다. 이미 발견된 조각의 ID·파트·위치·포인트 변경은 거부하고 문구 수정만 허용한다. 최초 기본 양식 생성은 편집창만 변경하며 저장·게시 버튼을 누르기 전에는 서버를 변경하지 않는다.

## 스토리 공개와 보상 수령

시즌 중에는 **9조각 수집 후 파트 완성 보상을 수령해야** 해당 파트의 이야기가 공개된다. 9조각을 모으기만 했거나 개별 조각 포인트 보상만 받은 상태에서는 이야기 본문을 서버가 보내지 않는다. 개별 조각 보상과 파트 희귀 보상은 별도이며, 파트 보상 수령 영수증으로 희귀 보상 지급과 이야기 공개를 연결한다. 다음 파트의 조각 수집 조건은 현재 파트의 9조각 발견 완료다.

시즌 종료 후에는 발견·수령 여부와 관계없이 13파트 이야기 전체를 공개한다. 이것으로 미수령 재화·희귀 보상을 지급하지 않는다. 공개 당시 내용을 서버 보관함에 고정하고 클라이언트는 공개 자료만 기존 로컬 업적 저장소에 보관한다. 빈 응답이나 이후 문구 수정으로 저장된 공개 이야기를 지우지 않는다. 시즌 중 개인 전용 이야기는 공개 보관함 파일에 저장하지 않는다.

운영자는 조사 수량 설정창에서 시즌 종료 시각을 한국 시간으로 지정할 수 있다. 기본 종료일은 미지정이다. 이미 공개한 시즌은 종료일을 뒤로 바꿔도 비공개로 되돌리지 않는다. 배틀패스는 파트별 페이지·3×3 조각판이며, 이야기 긴 본문에만 내부 스크롤을 사용한다.

## 방·저장소 배치 보정 (2026-10-25)
