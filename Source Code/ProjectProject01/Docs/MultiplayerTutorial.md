# 멀티 튜토리얼과 목표 안내

## 진입과 진행

- 로그인 후 **매칭 방식 선택 → 튜토리얼 → 생존자 / 마네킹**.
- 맵: `/Game/MyProject/Level/MultiplayerTutorial`. 멀티 Pawn·조작·시야 정지·공격 규칙으로 로컬 연습한다. 매칭, EOS 접속, 전적/리더보드 제출은 하지 않는다.
- 싱글과 싱글 체크포인트는 변경하지 않는다. 기존 팜플렛을 표시하거나 계정 초회 가이드 기록을 소비하지 않는다.
- 생존자: 역할·최종 목표 → 걷기 → 달리기 → 바라보며 마네킹 멈추기 → 핑 → 같은 맵의 탈출 영역.
- 마네킹: 역할·최종 목표 → 번호 선택 → V 직접 조작 → 이동 → 명령 저장 → 번호 선택으로 빙의 해제 → 연습용 생존자 **1명** 직접 붙잡기.
- 연습의 AI 접촉 피해는 끈다. 직접 조작 중 공격·접촉은 실제 규칙이다. 실제 보이스 통화는 연습하지 않는다.
- 중앙 설명은 시간이 지나도 닫히지 않는다. **확인 버튼만 눌러야** 실제 연습을 시작한다. 이동키·Enter·Space·ESC·화면 빈 곳/본문 클릭은 설명을 넘기지 않는다. 읽는 동안 이동/시점 입력을 잠근다. 긴 문구는 스크롤 가능.
- 연습 중 ESC로 현재 설명과 복귀 버튼을 다시 확인한다.
- 마지막 달성 → 역할별 인사(확인까지 유지) → 확인 → 1초 암전 → 튜토리얼 결과. 결과 버튼 순서는 **실전 연습 / 튜토리얼 처음부터 다시하기 / 로비로 돌아가기**다. 복귀할 때 세션이 없거나 만료됐다면 로그인 화면으로 간다.
- `실전 연습`은 같은 역할을 유지하고 맵을 초기화한 뒤 마지막 탈출/포획 연습부터 시작한다. 전체 역할·조작 설명은 반복하지 않는다. 마지막 상황 안내는 확인해야 한다. `튜토리얼 처음부터 다시하기`만 처음 역할 설명부터 반복한다. 실전 연습은 단계 배열 뒤에서 마지막 Trigger/Capture 조건을 선택한다(없으면 마지막 단계). 일반 로비 진입은 항상 처음부터 시작한다.
- 생존자 탈출은 현재 연습을 끝낼 뿐, 다른 층이나 맵으로 이동하지 않는다.

## 단계·문구 편집

맵의 `TutorialPlan_EditStepsAndMessages` (`ProjectProject01TutorialPlan`)을 선택한다.

- `Survivor Steps` / `Mannequin Steps`: +/−로 추가·삭제, 배열 순서 변경.
- `Id`: 중복 없는 단계 식별자.
- `Title`: 좌측 상단 목표 안내 문구.
- `Instructions`: 중앙 설명. 줄바꿈 가능.
- `Condition`: 달성 조건. `Continue`는 설명 확인만으로 다음 단계, 다른 조건은 확인 후 실제 행동을 해야 진행한다.
- `Required Amount`: 이동은 **cm**, 주시는 **초**, 다른 행동은 횟수.
- `Event`: `Trigger` 조건일 때 조건 트리거의 `Tutorial Event`와 맞춘다.
- `Survivor Closing` / `Mannequin Closing`: 마지막 인사 문구.
- `Practice Target Offset`: Plan 위치 기준 연습용 생존자 스폰 위치. 안전한 바닥 위로 지정.

`{Move}`, `{Sprint}`, `{Help}`, `{Danger}`, `{Location}`, `{PTT}`, `{Voice}`는 현재 키 설정으로 치환된다. 마네킹 고정 키는 기존 멀티 조작과 같다.

## 중앙 문구 트리거

`ProjectProject01TutorialMessageTrigger`를 배치한다. `Volume` 크기/위치, `Message`, `Required Step`, `Once`를 수정한다. Required Step을 비우면 진행 중인 어느 단계에서든 표시한다.

문구를 닫아도 현재 연습 단계는 바뀌지 않는다. 다른 설명을 읽고 있거나 종료 중이면 덮어쓰지 않는다. 튜토리얼 맵에서만 작동한다.

## 목표 갱신 / 달성 트리거

`ProjectProject01ObjectiveTrigger`는 일반 멀티 맵과 튜토리얼 맵에 배치할 수 있다.

| 항목 | 의미 |
|---|---|
| Required Objective | 진행 중인 목표가 일치할 때만 작동. 빈 값은 선행 제한 없음 |
| New Objective Id / Title / Instructions | 새 목표의 식별자·내용 |
| Complete Current Objective | 새 목표 대신 현재 목표를 달성 상태로 변경 |
| Audience | 진입자 / 생존자들 / 마네킹 플레이어 / 모두 |
| Once Per Player | 중복 접촉 안내 방지 |
| Tutorial Event | 현재 튜토리얼 단계 Event가 일치할 때 달성. 일반 경기에서는 무시 |

목표 UI는 **기존 체크포인트 저장 안내 위젯**이다. 좌측 상단에서 2.5초 선명하게 유지한 뒤 1.5초에 걸쳐 사라진다. 목표 상태는 서버에 남고 소유 클라이언트에게만 복제한다.

예: 단계를 `Id=EscapePractice`, `Condition=Trigger`, `Event=ReachedExit`로 추가한다. 영역에 `Required Objective=EscapePractice`, `Tutorial Event=ReachedExit`를 지정한다. 다른 단계에서 먼저 닿아도 건너뛰지 않는다. 마지막 단계면 연습 종료, 중간 단계면 다음 중앙 설명이다.

여러 번 필요한 Trigger 조건은 다른 영역들을 배치하고 같은 이벤트를 지정한다. 같은 영역의 중복 접촉은 기본값에서 한 번만 센다.

`Capture`는 단계당 연습용 생존자 한 명을 생성하는 조건이다. 기본 Required Amount는 1이며, 포획 연습을 추가하려면 Capture 단계를 하나 더 추가한다.

## 맵·실행·배포

- 에디터 **도구(Tools) → 멀티 튜토리얼 테스트 → 생존자 튜토리얼 테스트 / 마네킹 튜토리얼 테스트**로 직접 실행할 수 있다. PIE가 실행 중이면 먼저 종료한다. 서버·로그인·패키징이 필요 없다.
- 위 메뉴는 임시 Play 설정 복사본으로 **Standalone / 1명 / 별도 서버 없음**을 적용한다. 기존 멀티 PIE 모드·인원 수를 저장하거나 변경하지 않으며, 현재 편집 맵도 교체/저장하지 않는다. 역할 URL은 실행 시작 후 복원하고, 취소/실패/모듈 종료 때에도 복원한다.
- 일반 사용자 경로 **로비 매칭 선택 → 튜토리얼 → 역할 선택 → 연습 맵**은 변경하지 않는다. 도구 메뉴와 실행 보조 코드는 Editor 모듈에만 존재하여 패키징된 게임의 별도 우회 진입점이 되지 않는다.
- 에디터에서 연습 맵은 **Standalone / 플레이어 1명**으로 실행한다. 생존자 기본값, 마네킹 직접 실행 옵션은 `?TutorialRole=Mannequin`. 실제 경기의 Play As Client와 다르다.
- `Tools/CreateMultiplayerTutorial.py`는 최초 생성용이다. 기존 맵이 있으면 중단하며 덮어쓰지 않는다. 이후 에디터에서 수정한다.
- 기본 바닥·벽·표지·스폰 지점·동적 NavMesh를 제공한다. 지형 수정 뒤 내비게이션과 영역도 확인한다.
- 새 맵을 패키징 목록에 추가했다. 패키징은 별도 수행한다.
- 네트워크 컨트롤러 변경을 포함하므로 실제 배포 시 클라이언트와 데디 서버를 동일 소스/엔진으로 다시 빌드한다.

## 수동 확인

각 역할로 설명 유지/확인 버튼 → 실제 이동/달리기/주시/핑 또는 빙의/명령/직접 포획 → 목표 갱신 → 종료 문구 → 암전 → 결과 → 로비 복귀를 확인한다. 키 변경, 중간 ESC 안내 열기, 실전 연습과 처음부터 다시하기의 차이, 추가한 트리거도 확인한다. 기존 팜플렛은 뜨지 않아야 한다.

자동 검사가 실제 다중 PC의 전송 시점이나 최종 패키지 실행을 대신하지는 않는다. 최종 검사 결과는 별도 기록한다.
