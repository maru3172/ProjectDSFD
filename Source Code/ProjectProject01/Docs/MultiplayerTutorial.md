# 멀티 튜토리얼과 목표 안내

## 진입과 진행

- 로그인 후 **매칭 방식 선택 → 튜토리얼 → 생존자 / 마네킹**.
- 맵: `/Game/MyProject/Level/MultiplayerTutorial`. 멀티 Pawn·조작·시야 정지·공격 규칙으로 로컬 연습한다. 매칭, EOS 접속, 전적/리더보드 제출은 하지 않는다.
- 싱글과 싱글 체크포인트는 변경하지 않는다. 기존 팜플렛을 표시하거나 계정 초회 가이드 기록을 소비하지 않는다.
- 생존자(5단계): 역할·최종 목표 → 걷기 → 달리기 → 3초 동안 계속 바라보며 마네킹 멈추기 → 같은 맵의 탈출 영역. 핑·보이스 설명 단계는 없다.
- 마네킹(7단계): 역할·최종 목표 → 번호로 시점 3회 전환 → V 직접 조작 → 이동 → Z/X/C 중 원하는 명령·상태 확인 3회 → 명령 후 다른 번호 선택·AI 수행 관찰 3회 → 연습용 생존자 **1명** 직접 붙잡기.
- 걷기·마네킹 이동은 800cm와 실제 이동 4초, 달리기는 1,200cm와 실제 달리기 4초를 모두 충족해야 한다. 거리는 중앙 설명에 표기하지 않는다. 제자리 입력·대기·텔레포트만으로 넘기지 않는다.
- 같은 번호를 연속 눌러도 시점 전환 횟수가 늘지 않는다. 명령 단계는 Z/X/C 중 아무 명령이나 내리고 상태창을 1초 확인하는 연습을 3회 수행한다. 같은 명령도 반복할 수 있으며 빠른 연타는 확인 시간을 다시 시작할 뿐 횟수를 부풀리지 않는다. Q/B/직접 공격은 설명만 유지하고 이 단계의 필수 조건에서 제외한다. 명령 인계는 직접 조작 → Z/X/C → 다른 번호 선택 → AI 복귀 후 2초 관찰을 세 번 수행한다.
- 최종 포획 연습의 일반 AI 접촉 피해는 끈다. 직접 조작 중 공격·접촉은 실제 규칙이다. 앞선 B키 연습으로 바뀐 접촉 피해 설정도 이 단계에서 다시 끈다. 실제 보이스 통화는 연습하지 않는다.
- 연습용 생존자는 NavMesh의 도달 가능한 완전 경로로 이동하며 가까운 조작 마네킹을 피한다. 벽·구석에서 바깥쪽 도주 경로를 찾지 못하면 도달 가능한 다른 방향을 선택한다. NavMesh에 반영되지 않은 실시간 장애물은 캡슐 스윕으로 확인하고, 0.8초간 거의 전진하지 못하면 막힌 방향을 피해서 재탐색한다. 길을 찾지 못하면 0.35초 간격으로 재시도하며 벽을 통과하거나 텔레포트하지 않는다. 번갈아 마네킹을 돌아보고 시선을 돌려 견제 틈을 만든다.
- 중앙 설명은 시간이 지나도 닫히지 않는다. **확인 버튼만 눌러야** 실제 연습을 시작한다. 이동키·Enter·Space·ESC·화면 빈 곳/본문 클릭은 설명을 넘기지 않는다. 읽는 동안 이동/시점 입력을 잠근다. 긴 문구는 스크롤 가능.
- 연습 중 ESC로 현재 설명과 복귀 버튼을 다시 확인한다.
- 마지막 달성 → 역할별 인사(확인까지 유지) → 확인 → 1초 암전 → 튜토리얼 결과. 결과 버튼 순서는 **실전 연습 / 튜토리얼 처음부터 다시하기 / 로비로 돌아가기**다. 복귀할 때 세션이 없거나 만료됐다면 로그인 화면으로 간다.
- `실전 연습`은 같은 역할을 유지하고 맵을 초기화한 뒤 마지막 탈출/포획 연습부터 시작한다. 전체 역할·조작 설명은 반복하지 않는다. 마지막 상황 안내는 확인해야 한다. `튜토리얼 처음부터 다시하기`만 처음 역할 설명부터 반복한다. 실전 연습은 단계 배열 뒤에서 마지막 Trigger/Capture 조건을 선택한다(없으면 마지막 단계). 일반 로비 진입은 항상 처음부터 시작한다.
- 생존자 탈출은 현재 연습을 끝낼 뿐, 다른 층이나 맵으로 이동하지 않는다.

## 별도 자유 연습모드

- 같은 로비의 튜토리얼 선택에 **생존자 연습모드 / 마네킹 연습모드**를 추가한다. 기존 튜토리얼 설명·진행 및 결과의 `실전 연습`(마지막 단계 재연습)은 그대로이며, 자유 연습은 별도 경로다.
- 맵은 동일한 `MultiplayerTutorial`. 서버·EOS·실제 전적 제출 없이 로컬에서 멀티 규칙으로 연습한다. 기존 팜플렛도 표시하지 않는다.
- 두 역할 모두 마네킹 수 **1~10개**를 정할 수 있다(0~9 번호 체계). 마네킹 역할에서는 생존자 AI **1~2명**도 선택한다. 생존자 역할의 추가 동료 AI는 생성하지 않는다.
- 인게임 우측 전용 UI의 버튼으로 펼치기/접기. 게임 조작 중에는 **ESC**로 커서를 돌려 설정을 연다. 설정을 열면 일시정지되고 접으면 조작을 재개한다. 초기 준비/암전 해제 예약이 완료되기 전에는 일시정지하지 않아 영구 검은 화면을 피한다.
- 마네킹 수와 생존자 AI 수 모두 숫자 직접 입력과 **− / +** 버튼을 제공한다. 숫자칸 아래 별도의 가로 게이지 바는 제거했다. 생존자 연습에서는 마네킹 수를 조절하며, 생존자 AI 수 조절은 마네킹 연습에서만 표시한다. 범위 밖으로는 증가/감소하지 않는다.
- 역할 전환은 반대 역할 버튼 하나만 표시한다. 마네킹 연습에는 `생존자 연습으로 전환`, 생존자 연습에는 `마네킹 연습으로 전환`만 있다.
- 마네킹 자유 연습에만 `생존자 AI 제자리 대기` / `대기 중 주변 경계` 토글을 제공한다. 제자리 대기가 꺼져 있으면 기존 이동·달리기·협력 AI를 유지한다. 켜져 있으면 이동하지 않으며, 경계를 켜면 실제 시야를 좌우로 천천히 돌리고 끄면 처음 시야를 고정한다. 일반 튜토리얼·실제 경기 AI는 변경하지 않는다. 두 옵션도 `인원 적용 / 다시 연습`으로 반영하며 역할 전환/재시작 URL에 보존한다.
- 포획·사망·탈출 후 자동으로 재시작하지 않는다. 기존 `인원 적용 / 다시 연습`을 누르면 선택한 인원으로 맵과 상태를 초기화하며, 죽은 연습 생존자는 살아 있는 새 Pawn으로 다시 생성한다. 생존자 탈출 후에도 마네킹 수를 바꾼 뒤 같은 버튼으로 처음부터 다시 시작한다. 별도 `이어서 계속하기` 버튼은 추가하지 않는다.
- `인원 적용 / 다시 연습`, `생존자 연습으로 전환`, `마네킹 연습으로 전환`은 선택한 인원을 URL에 보존하고 같은 맵을 새로 불러온다. 이전 Pawn·명령·사망·관전 상태가 섞이지 않게 한다. URL 숫자도 마네킹 1~10, 생존자 1~2로 제한한다.
- 생존자는 탈출하거나 죽으면, 마네킹은 생존자 전원이 붙잡히면 연습이 끝난다. 결과를 실제 서버에 등록하지 않는다. 종료 연출 후 설정을 다시 열어 재시작·역할 전환·로비 복귀할 수 있다.
- 생존자 AI는 튜토리얼에서도 걷기만 하지 않고 위협 근처에서 짧은 달리기/걷기를 반복한다. 실제 멀티 스태미나를 사용하고 부족하면 회복한다. Plan의 `Practice Target Speed` / `Practice Target Sprint Speed`로 속도를 조절한다(기본 220/550cm/s).
- AI가 두 명이면 각자의 경로·스태미나·주시 상태를 따로 관리한다. 분산 이동 → 재집결 → 교대 엄호를 반복한다. 재집결 시 서로 가까워지고, 엄호 역할은 마네킹을 바라보며 동료가 움직일 틈을 만든다. 엄호 시에도 실제 시야·벽 차폐 판정을 사용한다. 한 명이 붙잡히면 남은 한 명은 단독 회피를 계속한다.
- 에디터 Tools의 멀티 튜토리얼 테스트 메뉴에도 역할별 **연습모드 테스트**를 제공한다. 기존 PIE 인원·네트워크 설정을 저장/변경하지 않는다.

## 단계·문구 편집

맵의 `TutorialPlan_EditStepsAndMessages` (`ProjectProject01TutorialPlan`)을 선택한다.

- `Survivor Steps` / `Mannequin Steps`: +/−로 추가·삭제, 배열 순서 변경.
- `Id`: 중복 없는 단계 식별자.
- `Title`: 중앙 설명의 첫 문장이자 좌측 상단 목표 안내 문구.
- `Instructions`: 첫 문장 다음 **빈 줄 하나** 뒤에 나오는 중앙 설명. 내부 줄바꿈도 유지된다. 역할별 텍스트 파일의 괄호 메모와 구분선은 표시하지 않는다.
- `Condition`: 달성 조건. `Continue`는 설명 확인만으로 다음 단계, 다른 조건은 확인 후 실제 행동을 해야 진행한다.
- `Required Amount`: 이동은 **cm**, 주시는 **초**, 다른 행동은 횟수.
- `Minimum Practice Seconds`: 이동 단계에서 실제로 움직여야 하는 최소 시간. 이동량 조건과 함께 충족해야 한다.
- `Event`: `Trigger` 조건일 때 조건 트리거의 `Tutorial Event`와 맞춘다.
- `Survivor Closing` / `Mannequin Closing`: 마지막 인사 문구.
- `Practice Target Offset`: Plan 위치 기준 연습용 생존자 스폰 위치. 안전한 바닥 위로 지정.
- `Practice Target Speed / Roam Radius / Watch Seconds / Look Away Seconds`: 연습용 생존자의 이동 속도·탐색 반경·견제/시선 돌리기 시간. 기본값 220cm/s, 900cm, 1.5초/2.5초.

`{Move}`, `{Sprint}`, `{Help}`, `{Danger}`, `{Location}`, `{PTT}`, `{Voice}`는 현재 키 설정으로 치환된다. 마네킹 고정 키는 기존 멀티 조작과 같다.

## 중앙 문구 트리거

`ProjectProject01TutorialMessageTrigger`를 배치한다. `Volume` 크기/위치, `Message`, `Required Step`, `Once`를 수정한다. Required Step을 비우면 진행 중인 어느 단계에서든 표시한다.

문구를 닫아도 현재 연습 단계는 바뀌지 않는다. 다른 설명을 읽고 있거나 종료 중이면 덮어쓰지 않는다. 튜토리얼 맵에서만 작동한다.

## 목표 갱신 / 달성 트리거

`ProjectProject01ObjectiveTrigger`는 일반 멀티 맵과 튜토리얼 맵에 배치할 수 있다.

| 항목 | 의미 |
|---|---|
| Required Objective | 진행 중인 목표가 일치할 때만 작동. 빈 값은 선행 제한 없음 |
| New Objective Id / Title / Instructions | 새 목표의 식별자·내용 |
| Complete Current Objective | 새 목표 대신 현재 목표를 달성 상태로 변경 |
| Audience | 진입자 / 생존자들 / 마네킹 플레이어 / 모두 |
| Once Per Player | 중복 접촉 안내 방지 |
| Tutorial Event | 현재 튜토리얼 단계 Event가 일치할 때 달성. 일반 경기에서는 무시 |

목표 UI는 **기존 체크포인트 저장 안내 위젯**이다. 좌측 상단에서 2.5초 선명하게 유지한 뒤 1.5초에 걸쳐 사라진다. 목표 상태는 서버에 남고 소유 클라이언트에게만 복제한다.

튜토리얼의 **계속 표시되는 현재 목표 문구만** 마네킹 상태창의 실제 높이 아래 16px 간격으로 배치한다. 설명/결과 팝업 중에는 이 지속 문구를 숨긴다. `목표가 갱신되었습니다` / `목표를 달성했습니다`의 기존 알림 위치·유지/사라짐 시간은 변경하지 않는다. 일반 경기·싱글 체크포인트 알림도 변경하지 않는다.

예: 단계를 `Id=EscapePractice`, `Condition=Trigger`, `Event=ReachedExit`로 추가한다. 영역에 `Required Objective=EscapePractice`, `Tutorial Event=ReachedExit`를 지정한다. 다른 단계에서 먼저 닿아도 건너뛰지 않는다. 마지막 단계면 연습 종료, 중간 단계면 다음 중앙 설명이다.

여러 번 필요한 Trigger 조건은 다른 영역들을 배치하고 같은 이벤트를 지정한다. 같은 영역의 중복 접촉은 기본값에서 한 번만 센다.

`Capture`는 단계당 연습용 생존자 한 명을 생성하는 조건이다. 기본 Required Amount는 1이며, 포획 연습을 추가하려면 Capture 단계를 하나 더 추가한다.

## 맵·실행·배포

- 에디터 **도구(Tools) → 멀티 튜토리얼 테스트 → 생존자 튜토리얼 테스트 / 마네킹 튜토리얼 테스트**로 직접 실행할 수 있다. PIE가 실행 중이면 먼저 종료한다. 서버·로그인·패키징이 필요 없다.
- 위 메뉴는 임시 Play 설정 복사본으로 **Standalone / 1명 / 별도 서버 없음**을 적용한다. 기존 멀티 PIE 모드·인원 수를 저장하거나 변경하지 않으며, 현재 편집 맵도 교체/저장하지 않는다. 역할 URL은 실행 시작 후 복원하고, 취소/실패/모듈 종료 때에도 복원한다.
- 일반 사용자 경로 **로비 매칭 선택 → 튜토리얼 → 역할 선택 → 연습 맵**은 변경하지 않는다. 도구 메뉴와 실행 보조 코드는 Editor 모듈에만 존재하여 패키징된 게임의 별도 우회 진입점이 되지 않는다.
