# 게임패드 (설계, 2026-11-11)

Xbox 패드(XInput)와 PlayStation 패드(DualShock 4·DualSense)를 지원한다. PlayStation 패드는 스팀(Steam Input)이나 DS4Windows를 거쳐 Xbox 패드로 들어온다. 메뉴는 가상 커서로 조작하고, 화면의 조작 안내는 마지막으로 만진 장치에 맞춰 바뀐다. 패드 버튼도 설정에서 바꿀 수 있다.

표기: Xbox / PlayStation. LT·RT = L2·R2, LB·RB = L1·R1, L3·R3 = 스틱 누르기, 메뉴 = OPTIONS, 보기 = 터치패드(Create).

## 1. 생존자 (경기·싱글플레이·튜토리얼)

| 조작 | 키보드 | 패드 |
| --- | --- | --- |
| 이동 / 시점 | W·A·S·D / 마우스 | 왼쪽 스틱 / 오른쪽 스틱 |
| 달리기 (누르는 동안) | Left Shift | LT / L2 |
| 상호작용 | F | A / × |
| 손전등 (사용자 지정 게임) | F | Y / △ |
| 도움 핑 / 위험 핑 / 위치 핑 | E / R / T | 십자 왼쪽 / 십자 오른쪽 / 십자 위 |
| 누르는 동안 음성 송신 | F2 | RT / R2 |
| 음성 송신 고정 전환 | U | 십자 아래 |
| 관전 대상 이전 / 다음 (탈락·탈출 후) | ← / → | LB / RB |
| 게임 메뉴 | ESC | 메뉴 / OPTIONS |

- 상호작용(A)과 손전등(Y)을 나눈 것은 키보드에서 둘 다 F라 사용자 지정 게임에서 겹치기 때문이다.
- 핑은 십자 키 세 방향에 모았다. 이동·시점 중에도 왼손 엄지를 잠깐 옮겨 누를 수 있다.

## 2. 마네킹 플레이어

| 조작 | 키보드·마우스 | 패드 |
| --- | --- | --- |
| 직접 조작 이동 / 시점 | W·A·S·D / 마우스 | 왼쪽 스틱 / 오른쪽 스틱 |
| 마네킹 시점 선택 (0~9) | 숫자 키 | LB 이전 · RB 다음 번호 |
| 명령 휠 열기 (조준한 마네킹) | 오른쪽 클릭 | LT / L2 |
| 휠에서 고르기 / 실행 / 닫기 | 마우스 / 왼쪽 클릭 / 오른쪽 클릭·ESC | 오른쪽 스틱 방향 / A·RT / B·LT |
| 직접 조작 중 공격 | 왼쪽 클릭 | RT / R2 |
| 게임 메뉴 | ESC | 메뉴 / OPTIONS |

- 슈팅 게임처럼 LT로 겨누고(휠) RT로 실행(공격)한다.

## 3. 관전·리플레이·카드 고르기

| 화면 | 패드 |
| --- | --- |
| 관전(오픈 관전 포함) 대상 이전 / 다음 | LB / RB |
| 오픈 관전 자유 시점 (Alt를 누르는 동안) | LT를 누르는 동안 |
| 리플레이 시점 전환 (오른쪽 클릭) | LT |
| 아이템 로그라이크 카드 1·2·3 / 다시 뽑기 (1·2·3 / R) | 십자 왼쪽·위·오른쪽 / X·□ |
| 규칙 카드 투표 1·2·3 | 십자 왼쪽·위·오른쪽 |

## 4. 메뉴 (가상 커서)

마우스 커서가 보이는 화면(타이틀, 로비, 사건 기록, 휴대폰, 설정, 커스텀 규칙, 게임 메뉴 등)에서는 패드가 커서를 움직인다.

| 조작 | 패드 |
| --- | --- |
| 커서 이동 | 왼쪽 스틱 (조금 기울이면 천천히) |
| 클릭 | A / × |
| 뒤로·닫기 (ESC) | B / ○ |
| 스크롤 | 오른쪽 스틱 위아래 |
| 방향키 (목록·미니게임 이동) | 십자 키 |
| 스페이스 (미니게임 확인·셔터 등) | X / □ |
| Q / E (한 칸씩: 제자리 돌기) | LB / RB |
| Z / R (한 칸씩: 되돌리기 / 처음부터) | 보기 / Y·△ |
| 게임 메뉴 열고 닫기 | 메뉴 / OPTIONS |

- 글자 입력 칸을 누르면 Windows 화상 키보드 대신 그 칸에 커서만 두고, 실제 입력은 키보드로 한다(패드로 긴 글을 쓰는 화면은 없다).

## 5. 설정

- 환경설정 조작 탭에 "게임패드" 묶음: 1~3장의 버튼을 키보드처럼 바꿀 수 있다(같은 화면에서 겹치면 경고). 기본값 되돌리기.
- 시점 감도(가로·세로), 세로 반전, 커서 속도, 스틱 데드존.
- 패드 버튼 표기: 자동(마지막 패드) / Xbox / PlayStation.

## 6. 장치와 안내 문구

- 마지막으로 만진 장치(키보드·마우스 / Xbox / PlayStation)를 기억하고, 바뀌면 조작 안내·버튼 표기를 바로 바꾼다(예: "F 상호작용" → "A 상호작용" → "× 상호작용").
- PlayStation 패드는 스팀(Steam Input)이나 DS4Windows가 Xbox 패드로 바꿔 넘긴다. 언리얼 RawInput 플러그인은 십자 키(햇 스위치)를 읽지 못해 쓰지 않는다. 이 경로로는 게임이 패드 종류를 알 수 없으므로, 설정의 "버튼 표기"에서 PlayStation을 고르면 ×○□△로 보인다(자동은 Xbox 표기).
- 실제 패드로 눌러 보는 확인은 패드를 연결한 PC에서 해야 한다.

## 7. 진동

- 심장 박동: 마네킹이 가까워질수록 빨라지는 약한 박동(화면 심박 효과와 같은 박자).
- 붙잡힘·피해: 짧고 강하게. 방화셔터가 내려올 때·엘리베이터가 덜컹일 때. 불길 속: 약하게 계속. 마네킹 플레이어 공격: 짧게.
- 설정: 진동 켜기·끄기, 세기 0~100%.
- 되는 패드: Xbox, 스팀이나 DS4Windows를 거친 패드(Steam Deck·Steam Controller·PlayStation). 라이트바·적응형 트리거·정밀 햅틱은 소니 SDK가 필요해 넣지 않는다.

## 8. 패드 연결이 끊겼을 때

- 싱글플레이: 바로 일시정지하고 일시정지 메뉴 위에 "패드 연결이 끊겼습니다. 다시 연결하거나 키보드로 계속하세요."를 띄운다. 다시 연결되면 안내만 사라지고, 플레이어가 "계속하기"를 눌러야 재개한다.
- 멀티플레이(멈출 수 없음): 같은 안내를 화면 위쪽에 띄우고, 다시 연결되면 닫는다.
- 패드를 쓰던 중일 때만 띄운다(키보드로 하던 사람이 꽂혀 있던 패드를 뽑아도 띄우지 않는다).

## 9. 스팀 패드 (Steam Deck · Steam Controller)

- 스팀으로 실행하면(스팀에 등록한 게임이든 "비 스팀 게임 추가"든) Steam Input이 스팀 패드를 Xbox 패드로 바꿔 넘긴다. 게임은 위 배치 그대로 받는다. Steamworks(스팀 SDK)는 넣지 않는다.
- 버튼 표기: 스팀 패드도 A·B·X·Y 글자를 쓰므로 Xbox 표기와 같다. **Steam Deck**에서 실행 중이면(스팀이 알려 주는 `SteamDeck=1`) 어깨 버튼을 L1·R1·L2·R2로, 메뉴 버튼을 "☰"로 표기한다.
- Steam Deck 화면(1280×800, 16:10)에서 메뉴와 안내가 잘리지 않는지 화면 검사에 넣는다. 터치스크린은 마우스로 들어와 그대로 쓸 수 있다.
- 글자 입력: Steam Deck에서는 스팀 화상 키보드(STEAM + X)를 쓴다.
- 스팀 패드의 터치패드·자이로·뒷버튼은 스팀 설정에서 원하는 키·마우스에 연결해 쓴다. 게임 안에서 따로 다루려면 Steamworks가 필요하며(스팀 출시 시), 이번 범위에는 넣지 않는다.

## 10. 구현 (2026-11-11)

- `Public/ProjectGamepad.h`, `Private/ProjectGamepad.cpp`: 게임패드 서브시스템과 입력 처리기(Slate 입력 전처리기).
  - 오른쪽 스틱 → 마우스 이동(플레이어의 마우스 감도와 모든 카메라가 그대로 적용), 패드 버튼 → 지금 모드에 맞는 키보드 키·마우스 버튼(`ProjectGamepad::Translate`).
  - 모드: 메뉴(커서가 보이거나 일시정지) / 명령 휠 / 생존자 / 마네킹 플레이어 / 오픈 관전 / 리플레이. 카드 고르기가 열려 있으면 십자 키·X가 카드에 먼저 쓰인다.
  - 왼쪽 스틱: 생존자·마네킹 직접 조작은 Enhanced Input에 `Gamepad_Left2D`(데드존 포함)를 더해 아날로그로 걷고, 관전·자유 카메라에서는 이동 키를 대신 누른다.
  - 마지막 장치 기억(키보드·마우스 / 패드), 진동(심장 박동 소리와 같은 박자, 피해, 셔터, 엘리베이터, 불길, 마네킹 공격), 연결 끊김 안내와 싱글 일시정지.
- `Public/ProjectPadSettingsPanel.h`, `Private/ProjectPadSettingsPanel.cpp`: 환경설정 › 조작 아래 "게임패드" 묶음. 버튼을 누른 뒤 패드 버튼을 누르면 바뀐다(Esc 취소). 같은 화면에서 겹치면 빨간 글씨로 경고한다.
- 설정 저장: `UProjectProject01GameUserSettings`의 `PadBindingNames`, `PadLookSpeedX/Y`, `bPadInvertY`, `PadCursorSpeed`, `PadDeadZone`, `PadGlyphs`, `bPadVibration`, `PadVibrationStrength`.
- 안내 문구: 게임 가이드 조작표, 튜토리얼 문구, 상호작용 표시(위젯의 "F"와 "F 키: …"), 프롤로그, 미니게임 설명이 패드를 쓸 때 패드 버튼으로 바뀐다.
- 마네킹 이전·다음 번호: `AMultiplayTestPlayerController::CycleMannequinSlot`.
- 검사: `ProjectProject01.Gamepad.Mapping`(기본 배치·표기·모드별 의미·버튼 변경·설정 패널).
- 남은 확인: 실제 Xbox·PlayStation(스팀/DS4Windows)·Steam Deck 패드로 눌러 보기, 진동 세기 조정, Steam Deck 1280×800 화면.
