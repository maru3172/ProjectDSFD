[회의 내용 정리]

1. 회의 개요

- 회의명: 주말회의
- 기록 기준일: 2026년 11월 3일 화요일
- 실제 회의 일시: 주말에 진행된 회의이나 정확한 날짜와 시각은 미확인. 파일명은 최종 결정안 전달일을 기준으로 작성했다.
- 주요 안건: 멀티플레이 마네킹 플레이어의 마네킹 조작 인터페이스 수정
- 기록 방식: 별도의 회의 기록이 없어 사용자가 전달한 최종 결정안을 기준으로 작성했다.

2. 명령 대상 지정 방식

- 마네킹 플레이어가 마우스 우클릭으로 명령 UI를 호출한다.
- 우클릭 시 발사한 레이가 다른 마네킹에 적중하면 해당 마네킹을 명령 대상으로 지정한다.
- 레이가 다른 마네킹에 적중하지 않고 허공을 가리키면 마네킹 플레이어 자신을 명령 대상으로 지정한다.
- 선택한 대상에 따라 동일한 명령 UI에서 다른 마네킹 또는 자신에게 명령을 내릴 수 있도록 한다.

3. 명령 UI 조작 방식

- 명령 UI는 감정표현 선택 창과 같은 원형 메뉴 형태로 구성한다.
- 명령 UI가 표시된 동안에는 화면과 시점이 움직이지 않도록 고정한다.
- 원형 메뉴에서 원하는 명령을 가리킨 뒤 마우스 좌클릭으로 선택한 명령을 실행한다.
- 명령 UI가 열린 상태에서 마우스 우클릭을 한 번 더 누르면 명령 선택을 취소하고 UI를 닫는다.

4. 추가 명령 및 조작 기능

- 빙의 기능을 추가해 마네킹 플레이어가 다른 마네킹으로 시점을 옮길 수 있도록 한다.
- 명령 항목에 빙의, 직접 조작, 정지를 추가한다.
- 빙의와 직접 조작의 관계 및 빙의 해제 방식은 이번 최종 결정안에 상세히 기록되지 않았으므로 구현 과정에서 구체화해야 한다.

5. 기본 입력 흐름

1) 마우스 우클릭으로 레이를 발사한다.
2) 레이가 다른 마네킹에 적중하면 해당 마네킹을, 적중하지 않으면 자신을 대상으로 지정한다.
3) 화면과 시점을 고정한 상태로 원형 명령 UI를 표시한다.
4) 마우스 좌클릭으로 빙의, 직접 조작, 정지 등의 명령을 선택해 실행한다.
5) 명령을 실행하지 않을 경우 마우스 우클릭을 다시 눌러 취소한다.

6. 결정 사항

- 우클릭 레이 적중 여부로 다른 마네킹과 자신 중 명령 대상을 구분한다.
- 명령 UI는 원형 메뉴로 제작한다.
- UI가 열려 있는 동안 화면 이동을 제한한다.
- 좌클릭은 명령 실행, UI가 열린 상태의 추가 우클릭은 명령 취소에 사용한다.
- 다른 마네킹으로 시점을 옮기는 빙의 기능을 추가한다.
- 명령 메뉴에 빙의, 직접 조작, 정지를 포함한다.

7. 구현 시 확인할 사항

- 레이가 월드 오브젝트에 적중했지만 마네킹에는 적중하지 않은 경우를 허공과 동일하게 처리할지 확인해야 한다.
- 원형 UI에서 명령 항목을 선택하는 방식과 커서 표시 여부를 정해야 한다.
- UI 표시 중 제한할 입력 범위를 카메라 회전만으로 할지, 이동까지 포함할지 확인해야 한다.
- 빙의 대상 조건, 빙의 해제 입력, 기존 조작 마네킹의 상태를 정해야 한다.
- 직접 조작과 빙의가 별도 명령인지, 빙의 후 직접 조작으로 이어지는 단계인지 확인해야 한다.
- 정지 명령의 지속시간과 다른 명령을 받았을 때의 해제 조건을 정해야 한다.

※ 이 문서는 회의 당시의 전체 논의 기록이 아니라 전달받은 최종 결정안을 정리한 기록이다. 구현 세부사항은 후속 논의에서 보완한다.


[회의 전문]

※ 별도의 회의 녹취나 전문은 작성되지 않았다. 아래는 사용자가 전달한 최종 결정안 원문이다.

우클로 다른 마네킹(레이를 쐈을때 적중 시 걔한테 명령)
우클로 다른 마네킹이 아닌 허공(자신한테 명령)
UI가 띄워진 상황에선 화면 움직임 X
명령 UI는 감정표현 같은 원형 UI
-> 이 상태에서 좌클로 선택한 명령 수행
우클 한번 더 누르면 명령 취소
시점 옮겨갈 수 있는 빙의도 추가
빙의랑 직접 조작, 정지도 추가
