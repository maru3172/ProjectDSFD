[추가 및 수정 전달사항]

작업 일시: 2026년 10월 29일 04:35 (Asia/Seoul)
작업 대상: Document/통합_게임_기획서.txt
작업 성격: 사용자의 최신화 요청에 따라 현재까지의 회의록과 10월 28일까지의 Git 커밋을 대조한 문서 정리

1. 실제 반영한 내용

1.1 문서 기준일과 자료 범위
- 최신화 기준일을 2026년 10월 29일로 변경했다.
- MeetingLog의 9월 2일~10월 18일 기록과 10월 28일까지의 관련 Git 커밋·구현 문서를 자료 범위에 추가했다.
- 회의의 구현 보고, Git에서 확인한 변경, 미확정 기획을 서로 구분하도록 기록 원칙을 보완했다.

1.2 마네킹 추적 영역과 행동 전환
- 관련 항목: 4.6 최신 추적 범위와 행동 전환, 4.7 랜덤 목적지와 추격 전환 확률 검토
- 수정 전: 영역 경계를 넘으면 안팎 구분 없이 즉시 새 행동으로 전환한다고 적혀 있었다.
- 수정 후: 9월 30일 후속회의의 최신 방식에 따라 안쪽 영역 진입은 즉시 전환하고, 바깥쪽으로 이동할 때는 기존 목적지에 도착한 뒤 새 영역 행동으로 전환한다고 정정했다.
- 10월 6일 사용자 확인 사항인 '랜덤 목적지는 추적 영역을 포함한 외곽 원 전체에서 선택하며, 이동 경로가 추적 영역에 들어가면 추격한다'를 추가했다.
- 직선·균일 분포 단순화 결과인 추격 전환 약 64.0%, 추격 전환 중 전방 약 63.3%·후방 약 36.7%를 검토값으로 기록했다. 실제 NavMesh·맵 밀도를 대신하지 않는다고 명시했다.

1.3 광원과 심박수
- 관련 항목: 6.2 10월 구현 보고와 현재 범위, 7.7 기본·조우 심박 분리 구현
- 조명이 비추는 범위의 마네킹 수가 많을수록 점멸 주기가 짧아지는 10월 구현 보고와 환경별 로딩 오류 해결 이력을 추가했다.
- 기본 심박 시야와 조우 심박 시야, 장애물 판정, 재조우 기억을 분리한 최신 구조와 새 설정 변수 10개를 추가했다.
- 9월 30일 교수 피드백에 따라 광원·심박 연출은 주요 시스템 완성도보다 후순위이며 폐기 결정은 아니라는 점을 기록했다.

1.4 10월 개발 우선순위와 근거
- 관련 항목: 8.2, 11.1, 12장
- 저장·체크포인트, 멀티 역할과 명령, 튜토리얼, 엘리베이터, 피격, 상호작용, 방화셔터, 관전, 봇전과 UI의 진행 상태를 추가했다.
- 9월 30일 전체미팅·후속회의, 10월 4일·13일·18일 회의록과 10월 Git 커밋을 근거 목록에 추가했다.
- 구현 커밋과 실제 배포 완성도는 다르며, 여러 PC·패키징·네트워크·청감·난이도 검증이 필요하다고 구분했다.

1.5 멀티플레이 최신 구현
- 관련 항목: 13.2, 13.10
- 9월 E/R 입력 보고는 이력으로 남기고, 10월 보고의 Z/X/V/C/Q/B 및 좌클릭 공격을 최신 역할별 입력으로 추가했다.
- 가이드북, 멀티 튜토리얼·자유 연습, 역할별 핑, 비상 엘리베이터, 관전·층 이동, 봇전과 PvP 기록 분리를 추가했다.
- 구현된 엘리베이터는 현재 층 전환 수단이며 기존 지하 구출 미니게임의 채택 확정이 아니라고 구분했다.

1.6 싱글 진행·연출 및 상호작용
- 새 14장에 저장 슬롯·체크포인트, 메신저·구매 체크리스트 인트로, 파트너 첫 대면과 구출 튜토리얼, 방화셔터 배치·F키 상호작용, 피격·사망·이동 피드백, 공간 사운드, 타이틀 연출을 정리했다.
- 회의에서 제안한 싱글 인트로와 Git에서 구현된 멀티 튜토리얼을 별개로 구분했다.
- 정상 작동 셔터와 고장 난 장애물 셔터의 배치 목적, 현재 테스트 구현과 최종 레벨 배치를 구분했다.

1.7 온라인·봇전 확장
- 새 15장에 랜덤·오픈 매칭, 커스텀 규칙, 관전·리플레이, PvP·봇전 기록 분리와 5단계 적응형 봇 구현을 요약했다.
- 회의 합의가 없는 커밋 기반 기능은 현재 구현 현황이며 영구 핵심 기획으로 자동 확정하지 않는다고 명시했다.

2. 변경 이유와 근거

- 통합 기획서의 기존 최신화 범위가 9월 26일까지여서 9월 30일 이후 회의 내용과 10월의 대규모 구현 변화가 누락돼 있었다.
- 마네킹 영역 전환은 9월 30일 회의에서 기존 즉시 전환 방식이 명확히 변경됐으므로 최신 개발 방식으로 정정했다.
- 10월 13일·18일 회의록에는 플레이 흐름과 조작에 직접 영향을 주는 인트로, 셔터, 저장, 피격, 상호작용, 정찰, 사운드가 추가됐다.
- 10월 18일 이후 커밋에서 엘리베이터·튜토리얼·방화셔터·관전·봇전·UI가 실제 소스와 구현 문서로 추가·보완돼 현재 상태를 별도 기록할 필요가 있었다.

3. 보존한 기존 내용

- 파트너와의 유대감, 시야 분담, 미인지 적을 심박으로 미리 알리지 않는 방향, 기존 엔딩·지하 구출 검토안은 삭제하지 않았다.
- 회의록과 충돌하지 않는 사용자 작성 설명과 과거 검토안은 이력으로 보존했다.
- 봇전·온라인 기능이 추가됐다는 이유로 기존 싱글플레이와 3인 PvP 기획을 대체하지 않았다.
- 현재 작업 트리의 맵 FBX와 Blender 파일 수정은 변경하거나 되돌리지 않았다.

4. 다음 회의에서 확인할 사항

- 랜덤 배회의 실제 NavMesh 경로에서 추격 전환율과 전후방 체류 밀도가 직선 검토값과 얼마나 다른지 측정할지 결정한다.
- 싱글 인트로의 선택 구매 이점, 트리거 거리, 최종 대사와 본편 연결을 확정한다.
- 파트너의 시야·심박·포획·구출·데스카운트 관계와 지하 구출 채택 여부를 확정한다.
- 멀티 공식 기본 규칙, 한 명 탈출·한 명 포획의 승패, 봇전 표시·보상·난이도 및 커스텀 경기의 범위를 최종 승인한다.
- 접근성 기본값과 화면 효과·카메라 흔들림·점멸·공간 사운드의 실제 플레이 테스트 기준을 정한다.

5. 미정 사항과 구현 현황의 구분

- 회의에서 제시된 제안·일정·검토안은 확정 기능으로 바꾸지 않았다.
- Git 커밋으로 확인한 기능은 '구현 현황'으로 기록했으며 실제 패키징·배포·다중 PC 검증 완료로 확대하지 않았다.
- 봇전과 온라인 확장 기능은 현재 빌드의 구현 사실을 반영한 것이며 팀의 장기 핵심 기획 합의를 대신하지 않는다.
